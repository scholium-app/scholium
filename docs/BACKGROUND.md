# 背景：前两次尝试为什么失败

本文记录 Scholium 之前两轮方案的失败原因，作为设计约束的依据。
内容截至 2026-07-28，是对当时状态的快照，不再更新。

Scholium 不复用这两轮的任何代码。

## 起点：Mogan STEM

基于 GNU TeXmacs 的 C++/Qt6 科学写作应用。

| 维度 | 规模 |
|---|---|
| 核心 C++ 源码 | 671 文件 / 20.7 万行 |
| Scheme 脚本 | 372 文件 / 11.7 万行 |
| 第三方 C/C++ | ~1,634 文件 |
| GUI | Qt6 |
| C++ 标准 | C++17 |
| 构建 | xmake |
| C++ ↔ Scheme 绑定 | ~670 个函数 |

Scheme 层承担菜单命令、文档宏、插件扩展、编辑器 API 脚本调用。
11.7 万行业务逻辑压在解释器上，是重写时最大的存量负担。

## 第一轮：Typst 源码编辑（Tauri + Svelte + CodeMirror）

技术栈：Tauri v2 + Svelte + CodeMirror 6 + typst-ide。
体验模型是「源码 + 预览」双栏——左边编辑 Typst 源码，右边看渲染结果。

计划了 8 个阶段、30 周到 1.0，范围覆盖编译管线、编辑器增强、格式转换
（1500-2000 条 LaTeX→Typst 映射规则）、文献管理、版本控制、AI 魔法粘贴、
国际化打包。

**失败原因一：放弃了唯一的差异化能力。**
源码编辑模式下，Mogan 最有辨识度的结构化数学输入手感（数学环境、Tab 循环、
乐高符号、结构变体、矩阵快捷编辑）全部消失。做出来就是一个 Typst 编辑器，
而市面上已经有了。

**失败原因二：范围排布倒置。**
把最不可替代的编译管线排在阶段 1，却先把 `mogan-ai`、`mogan-bib` 的目录建好了。
最终排版闭环一行未通。

## 第二轮：结构化数学编辑（Tauri + Svelte + Tiptap）

在第一轮脚手架上改路线：主编辑器从 CodeMirror 换成 Tiptap/ProseMirror，
主保存格式改为 `.mogan.json` 结构化文档，Typst 退为导出/预览格式。

这一轮的方向判断是对的——认定结构化 AST 而非 Typst 字符串才该是主模型。
数学 AST、乐高规则、Tab 循环等价类的设计基本可用，Scholium 的 §5、§7 沿用了它的思路。

**失败原因：管线仍然把 Typst 当导出器。**

```
AST → Typst 源码 → SVG → 塞进 iframe
```

这条路径上，屏幕上的字形和 AST 节点之间没有对应关系。于是点击无法定位到节点、
光标无法进入分母、矩阵单元格无法高亮。方案因此不得不规定：

- 编辑态公式用 KaTeX/MathLive 渲染（DOM）
- 整页预览用 Typst 渲染（SVG）

两套排版引擎、两种排版结果，所见永远非所得。而这是被管线逼出来的，不是选择。

## 实际完成度（2026-07-28 快照）

`mogan-rs` 仓库状态：

| 模块 | 计划状态 | 实际 |
|---|---|---|
| `mogan-typst::Compiler` | 阶段 1 核心 | 全是 `Ok(())` 空壳，`typst` crate 未被调用 |
| `mogan-typst::MoganWorld` | impl `World` | 空 struct，无 impl |
| `mogan-core::DocumentTree` | 结构化 schema | `{ root: String }` |
| `mogan-convert` | 1500+ 映射规则 | `translate()` 返回空串 |
| `mogan-ai` / `mogan-bib` | 阶段 4/6 | 空 struct |
| `Preview.svelte` | Typst SVG 预览 | 写死的假页面 |
| 前端数学原型 | 阶段 2-4 | 唯一真有内容，~3.7k 行 |

依赖里 CodeMirror 和 Tiptap 同时存在，是两版路线打架留下的残留。

## 结论：三条继承下来的约束

1. **Typst 必须是排版内核，不能是导出器。**
   反向映射（屏幕字形 → AST 节点）是结构化编辑的前提，管线设计要以它为中心。
   单引擎，不接受编辑态和出稿态用两套排版。
2. **结构化 AST 是唯一真相，不是 Typst 字符串。**
   这条继承第二轮的判断。
3. **范围纪律优先于功能广度。**
   两轮失败都是范围拖死的，不是技术拖死的。核心管线通了再谈其他。
