# 2026-11-03：全界面截图审查

## 范围与方法

用户指出 LaTeX 工作台、诊断面板和新建对话框都有问题，要求逐个检查全部界面后统一重画。
审查基于 `main` `d11c0c6`（#90–#98 合并后），用 `target/debug/scholium-app` 在私有 Xvfb `:99` 上运行，
配置目录隔离，中文与英文各跑一遍，共 63 张截图。驱动脚本复用 `spikes/typst-main-editor/project_ui.py`，
控件坐标取自应用的 AUDIT 输出。覆盖：
- Typst 原生项目：页面编辑、公式焦点、`\` 命令框、8 个菜单、诊断与导航面板、源码预览、隐藏工具栏、段落与字体下拉、新建/打开/另存为、480 px 窄窗口；
- `.typ` 源码项目与外部修改冲突；
- LaTeX 项目：无工具链、本机 rtex 实时预览（pin `531e2c6`）、XeLaTeX 整编、页面编辑切换；
- 项目已被另一进程打开。

下文引用的截图在 [evidence/ui-audit](evidence/ui-audit/)，为中文界面。英文界面没有发现文字截断。

测试工具的限制：`xdotool type` 在没有输入法的 Xvfb 中打不出中文，截图里“Scholium 笔记”中的“笔记”丢失是这个原因，不是应用缺陷。

## 发现

### 功能缺陷

1. LaTeX 源码里有未定义的 `\foo`，诊断面板仍显示“没有问题”：LaTeX 错误没有进入诊断面板。见 [l11](evidence/ui-audit/l11-live-diagnostics.png)。
2. `.typ` 源码项目只有一个 5 行高的输入框，没有预览。打开后输入框没有焦点，键入的文字丢失。见 [s01](evidence/ui-audit/s01-typ-source.png)。
3. 打开对话框后按 Esc 不关闭，之后按 Ctrl+Shift+S 截到的仍是打开对话框。见 [t31](evidence/ui-audit/t31-dialog-open.png)。
4. LaTeX 项目中点击“页面编辑”没有任何反应。
5. 480 px 窄窗口下对话框超出窗口，内容贴左边。见 [t40](evidence/ui-audit/t40-narrow.png)。

### 外壳没有按项目语言装配

6. LaTeX 与 `.typ` 源码项目显示 Typst 的文档属性行（样式/纸张/语言/字体/字号）、格式按钮和 Typst 含义的插入/格式/文档菜单。见 [l01](evidence/ui-audit/l01-no-toolchain.png)。
7. LaTeX 项目的诊断面板显示“后端：Typst Content”。

### 大量禁用入口

8. “文档”菜单全部禁用，“工具”菜单全部禁用，“帮助”3 项中 2 项禁用；主工具栏 5 个按钮、属性行 5 个下拉框禁用，Typst 项目里字体下拉点开没有反应。
   见 [t10-document](evidence/ui-audit/t10-menu-document.png)、[t10-tools](evidence/ui-audit/t10-menu-tools.png)、[t01](evidence/ui-audit/t01-start.png)。

### 开发信息与内部术语外露

9. 诊断面板右侧显示“正文 r27 / 画面 r27 / Content 新建 4 / 复用 3 · source reads 0 / 布局+栅格 1 ms”。见 [t20](evidence/ui-audit/t20-diagnostics.png)。
10. 生成源码标题“生成 Typst 源码 · 只读 · 正文 r27”；导航栏“未命名 · 结构会话 / 隔离开发文件”（#96 之后已不准确）；标签页显示 `default-project`。
    见 [t21](evidence/ui-audit/t21-navigation.png)、[t22](evidence/ui-audit/t22-source-preview.png)。
11. LaTeX 工作台显示 `missing SCHOLIUM_RTEX_TEXDIR`、`LuaLatex`/`XeLatex`、“LaTeX 源码工作台”“同引擎预览”“源码权威”“未保存编辑”（没有编辑也显示），状态栏同时出现“实时预览 · 0 ms”和“工具链不可用”。
12. 状态栏“Typst 预览”“源码权威”含义不清；“页面编辑”的悬停提示只重复按钮文字。

### 源码与预览

13. Typst 生成源码没有行号、语法高亮和当前块高亮（设计稿有）。
14. LaTeX 源码框高度固定，下方留空；没有行号；两栏不能拖动调宽。
15. LaTeX 预览只按 100% 显示在半栏中，字很小；状态栏缩放与“适合宽度”对它不起作用；缺工具链时预览区一片空白。见 [l10](evidence/ui-audit/l10-live.png)、[l20](evidence/ui-audit/l20-xelatex.png)。

### 对话框与空状态

16. 新建/打开对话框的路径输入框没有可见边框；“确定”“取消”是竖排的纯文字；没有标题栏关闭按钮、浏览按钮、名称和模板；LaTeX 不是默认语言；“迁移旧会话…”夹在路径标签和输入框之间。
    见 [t30](evidence/ui-audit/t30-dialog-new.png)、[t31](evidence/ui-audit/t31-dialog-open.png)。
17. 外部修改冲突对话框的三个操作是竖排纯文字，没有主次，说明挤在一行。见 [s02](evidence/ui-audit/s02-external-conflict.png)。
18. 项目被锁时只有一行红字，没说明是哪个项目，也没有重试操作；没有打开项目时只有一行“请从文件菜单新建或打开项目”。见 [x01](evidence/ui-audit/x01-locked.png)。

### 运行正常的部分

公式焦点栏、`\` 命令框、段落样式下拉、源码预览的分栏与页码导航、工具栏溢出“»”、XeLaTeX 整编预览、LuaLaTeX 实时预览均按预期工作，
LaTeX 预览字形放大检查正确。
