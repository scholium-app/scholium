# 2026-09-24：原生 Ribbon 功能区

按用户要求，先以带 DCO 的 `5a905d7` 提交了公式输入反馈与排版等待修复，再开始调整应用壳。
本次将传统菜单加单行工具栏改为带文件菜单的 Ribbon；布局变化的原因是让文字、公式、段落样式和
视图操作按任务分组可见。所见即所得仍直接编辑真实排版页，源码模式仍为生成源码与预览双窗格。

## 界面与行为

- 文档标签在顶部；其下为文件、开始、插入、布局、视图，右侧提供帮助和功能区折叠。
- 开始页提供文档、剪贴板、文字、段落样式、数学、历史分组。组名底部对齐，样式卡显示当前段落角色。
- 插入页提供行内与独立公式入口，布局和视图集中页面显示、缩放、面板与分屏操作。
- Ctrl+F1、收起按钮或双击标签可折叠；点击标签展开。640×480 窗口使用明确显示的水平滚动条访问完整分组。
- 剪贴板通过原生平台请求保留页面选区；公式与样式按钮在操作后恢复页面输入焦点。
- 新建、保存继续进入既有命令通道，段落样式和公式继续经本地会话修改权威内容。
- 源码视图的正文写按钮禁用；未接入的撤销、结构数学、对象插入和纸张设置等入口保持置灰。
- 文档标签的未保存圆点改为跟随实际保存 revision，状态栏页码跟随当前页面。

## 验证

Linux Xvfb / X11、eframe/egui 0.36.2，1280×900 与 640×480，1x DPI。
使用独立临时 SQLite 会话，未操作用户的已有文档或数据库。

```sh
cargo build --locked -p scholium-app
xvfb-run -a -s '-screen 0 1400x1000x24' python3 scripts/review-ribbon.py
```

真实窗口脚本通过 Ribbon 粘贴中文与公式、复制全选内容、剪切再粘贴，并用系统剪贴板逐次核对全文。
点击独立公式后逐字键入 `alpha/2`，核对生成的公式标记；点击标题 1 后继续输入，再点击保存。
从临时数据库读回五个块，确认独立公式内容、Heading1 类型及标题文字正确。
随后检查四个标签、只读源码模式、横向滚动、折叠以及点击标签展开的截图。

4 项新增 egui 事件测试覆盖标签/折叠不修改 revision、源码视图不能使用正文格式命令、
公式/段落样式后继续页面输入，以及平台粘贴请求保留原选区。全工作区 **71 项测试通过**；
格式、clippy warnings、文档 warnings 和 Rust 文件规模检查通过。

这次是功能区布局与现有命令接入验证，不代表结构数学、撤销、源码可写能力或跨平台 IME/读屏已经交付；
也不以短样本文档证明长文档输入性能。Ribbon 偏好仍只在会话内保存。
