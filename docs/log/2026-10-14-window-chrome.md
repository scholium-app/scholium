# 2026-10-14：窗口外壳——菜单栏、图标工具栏、焦点工具栏、标签栏、状态栏

本记录只追溯本次 PR 做了什么、怎么验证；行为规范见 [app.md](../modules/app.md#应用壳与主题边界)，布局基准见
[P1 排版工作区规划](../plan/P1_UI.md)，命令注册表见[上一份记录](2026-10-14-command-registry.md)。

## 做了什么

- 删除 Ribbon（`ribbon.rs`、`ribbon/`、`typst_editor/ribbon.rs`），顶部改为设计稿的四栏：菜单栏 28、主工具栏 34、
  焦点工具栏 30、文档标签栏 30，下方是编辑区，底部状态栏 24。窗口标题栏仍由系统绘制（`with_decorations(true)`）。
  四栏合计 122 逻辑像素（测试断言当前标签的底边落在 122）。
- `theme::Tokens`：P1_UI 令牌表的 24 个语义色（浅/深两套 HEX，测试逐项对表）、栏高、控件高、字号与行高、间距、圆角、图标尺寸。
  `theme` 之外没有颜色字面量（测试扫描 `src/` 里的 `Color32::from_rgb`）。浅色是默认主题；“视图 → 主题”运行时切换。
  纸面在两套主题中都是白色，所以画在纸面上的光标、选区与公式底色取浅色主题的强调色与 `math_bg`。egui `ScrollArea` 的边缘渐隐
  被关掉，否则深色主题下白纸上下边会出现一道灰带。
- `widgets/`：图标按钮、文字下拉框、分隔线（组 1×18、状态栏 1×12、菜单通宽）、标签页、模式分段切换、状态栏片段与警告、
  菜单项（右对齐快捷键、勾选、子菜单箭头）、“名称 + 快捷键”提示（禁用时第二行写原因）。默认、悬停、按下、激活、禁用、
  键盘焦点环（2px、外扩 1px，只在键盘操作后出现）都由令牌绘制。设计稿问题的修正：菜单宽度按最长一行测量，标签不再写
  “（未实现）”，原因放提示里；分段切换每段按文字测量且不小于 96；页面与纸张在“文档”菜单（注册表原本就在那里）。
- `icons`：Lucide 图标（ISC，`assets/icons/LICENSE`，取自 lucide 1.57.0）内嵌 SVG，用依赖图里已有的 `resvg` 按设备像素比光栅化，
  按（图标、尺寸、线宽、颜色、ppp）缓存并由令牌着色；工具栏 18/1.5、菜单与溢出 14/1.25、状态栏与标签 12/1.25、箭头 8/1.25。
  旧的手绘图标已删除；`IconId` 新增段落、标题 1/2、上下标、表格、图片、链接、定界符、矩阵、独立公式、离开公式。
- 字体：启动时用 `fontdb` 读系统字体库，按 HarmonyOS Sans SC → MiSans → 苹方 → 微软雅黑 UI → 微软雅黑选界面字体，
  西文优先 Inter，等宽优先 JetBrains Mono；随程序打包的 Noto Sans CJK 只作最后回退。所选字体写入 AUDIT `fonts`。
- 菜单栏由 `registry::menu_items`/`submenus` 生成，悬停另一个已展开菜单的标题会切换菜单；子菜单悬停展开。
  主工具栏按 `ToolbarPlacement` 分组，段落样式三项合并为一个“¶ ▾”下拉；命令搜索固定在最右并禁用（原因在提示里）；放不下的
  整组按注册表顺序收进“»”列表（图标 + 标题 + 快捷键）。焦点工具栏在正文显示五个禁用的文档属性下拉框（值读自
  `scholium_typst` 的样式常量），在公式显示“公式”标记与 `FocusKind::Math` 的命令，最右固定是模式分段切换。
  标签栏、状态栏按任务书实现：字数（CJK 字符 + 拉丁词，随快照修订重算）、页码只在源码模式显示、上下文、一条警告、
  缩放；后端与 revision 移入上下文片段的悬停提示，“视图 → 诊断”打开时布局统计另占一个片段。
- 命令注册表的调整：`view.ribbon` → `view.toolbars`（Ctrl+F1）；`view.theme` 拆成 `view.theme.light|dark`，新增
  `view.language.auto|zh_hans|en`（视图菜单的“主题”“语言”子菜单）；新增 `insert.exit_formula`（只在公式里可用，焦点栏用）；
  `file.close` 接上既有的关闭与丢弃确认流程（标签页的关闭按钮用它）；`insert.formula` 带勾选状态（光标在公式内时激活）。
- 文字目录：窗口外壳的全部可见文字走 Fluent（新增 `chrome-*` 与若干命令/原因 key，两种语言 key 集合仍相同）；窗口标题、
  丢弃确认框、标签标题也走目录。`i18n::text_with` 支持带参数的消息（字数、页码、修订、窗口标题）。允许列表删去 57 条。
- AUDIT 新增 `controls`（命令 id 或 `ui.*` 外壳 id 到每个可见控件的窗口像素矩形，菜单展开时含菜单行）、`chrome`（语言、主题、
  溢出分组、状态栏事实）与 `fonts`。`spikes/typst-main-editor/chrome_ui.py` 封装按 id 点击、悬停与等待矩形稳定；
  `a4-surface-check` 与 `source-view-check` 改为按 id 点击，新增 `chrome-check`（菜单、子菜单、工具栏、溢出、焦点栏随光标、
  标签页新建与关闭、状态栏字数与缩放、主题与语言切换、Ctrl+F1）；`a11y_check` 按 catalog 标题查控件名并检查开关角色；
  `interaction-check` 的公式底色计数只统计纸面区域（外壳的 active_bg 色相相同）。
- `scripts/window-checks.py` 增加 `--locale`（默认 zh-Hans，可给多个）；CI 的 `window` 作业改为 zh-Hans / en 矩阵。
- `spikes/typst-main-editor/chrome-shots.py`（不是检查）按尺寸 × 缩放 × 主题 × 语言 × 状态生成本记录的截图。

## 与规格的差异

- **最小窗口宽度 640 → 480。** 注册表目前只有段落下拉、文字 5、插入 5、历史 2 个工具栏命令，640 宽时整条工具栏放得下，“»”永远不出现，也就无法在真实窗口里
  验证溢出。降到 480 后最后一组（撤销/重做）会收进“»”，窗口检查与截图都能覆盖。设计稿的 1024×700 溢出图依赖列表、代码块等
  注册表里还没有的命令，所以 1024×700 的截图里不会出现“»”；溢出另有 480×700 的截图。
- **“视图 → 语言”“主题”是注册表命令（`view.language.*`、`view.theme.*`）**，不是外壳自带的特例；因此语言名称“简体中文”“English”
  在两种界面语言下都用各自的本名。
- **字体选择直接用 `fontdb`**（已在依赖图里，版本与 typst-kit 一致，`Cargo.toml` 里显式写出），不是共用 Typst 内核已经建好的字库实例；
  启动时多扫描一次系统字体。HarmonyOS Sans / MiSans / 苹方 / Inter / JetBrains Mono 在本机与 CI 都没有安装，所以截图用的是
  微软雅黑 UI（本机）或 Noto Sans CJK（CI），回退路径经测试覆盖了优先级选择。egui 只有一种字重，设计稿的 500/600 字重无法实现
  （激活的分段只换底色与强调色）。
- **文字下拉框没有展开列表**：五个文档属性都只读，没有使用者；展开列表（当前项勾选）留到属性可编辑时再做，菜单项控件已具备勾选能力。
- **标签标题**：显式 `SCHOLIUM_SESSION_FILE` 打开的文档显示文件名（不带扩展名），默认文档显示“未命名”，与此前窗口标题一致；
  `.typ` 之类的扩展名属于以后的文档打开流程。
- **焦点栏的数学命令**按注册表顺序列出（分数、根式、上下标、定界符、矩阵、离开公式），上标与下标是同一个“上下标”命令，没有单独拆开；
  设计稿里的“Esc”提示没有，因为注册表里 Esc 不是和弦。根式、上下标、定界符、矩阵尚未实现，显示为禁用。
- **状态栏的警告不可点击跳转**（设计稿写“点击跳到出错位置”）：没有可跳转的位置；它可聚焦，被拒绝输入时旁边有“复制”按钮。
  多条警告的“共 N 条”也没有做，状态栏本来就只有一条警告。
- **没有“诊断面板”**：诊断开关只让布局统计显示为一个状态栏片段；后端与 revision 在上下文片段的悬停提示里。
  AGENT.md 第 6 条“UI 必须始终显示当前后端和 revision”与此不一致，已在报告里提请协调者决定如何改写。
- **窗口检查没有在 `chrome-check` 之外给每个脚本都加“按 id 点击”**：其余脚本只有 `a4-surface` 用坐标点过外壳（已改），
  其他脚本用键盘或页面坐标。`source-view-check` 的第一次进出源码改用分段切换，其余仍用 Ctrl+Shift+M，因为那是被测的快捷键。
- 源码窗格标题、编辑面状态消息、无障碍朗读、启动错误页仍是硬编码中文，留在允许列表里（不属于外壳）。

## 评审后修订

- CI `window (zh-Hans)` 的 `chrome-check` 第 10 步“text typed”超时：该步用 `xdotool type` 输入含 CJK 的 " 中文 abc"。xdotool 对
  键盘映射里没有的字符会临时重映射一个空闲键码再发送，这一步与应用读取键盘映射的时机有竞争，在 CI 的 X 服务器上偶发丢字；
  本机连续 3 轮 × 2 种语言（共 6 次）都通过，步骤 01–09 的菜单、语言与主题切换后页面焦点是好的（该步先点击纸面取得焦点），
  没有发现应用侧的焦点问题。改为经剪贴板粘贴（`xclip` + Ctrl+V，其他检查已在用），断言不变。
- 截图重拍：文本/公式/菜单等状态都先把页面滚到顶部、光标放在第一段正文（公式状态在该段内），标题与前几段可见，可与设计稿对照；
  文件名不变，量化为 64 色无抖动，70 张共约 3.4 MB。
- 上标/下标：`insert.attach` 拆成 `insert.superscript`（显示 `^`）与 `insert.subscript`（显示 `_`），焦点栏数学上下文里分别可用，
  仅在光标位于公式内、非源码视图、非组合输入时启用；执行路径是新的 `Command::Attach(AttachSlot)`，与键入 `^`/`_` 共用
  `attach_slot`，没有重复行为。新增图标 `subscript`。测试：命令与键入建出相同的槽并落在槽内、正文里执行无改动、可用性三种禁用原因、焦点栏列出且启用。
  截图未重拍（焦点栏里原来灰着的“上下标”现为“上标”“下标”两项）。
