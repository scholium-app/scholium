# 基础 UI 收尾记录

本记录仅追溯原生应用壳的检查，不是编辑、排版或阶段出口能力证明。

## 修复

- 从适合宽度进入手动缩放时，以最近实际显示的页面比例为起点。
- 分隔条接受拖动或键盘输入后，同帧限制比例并更新布局。
- 分隔条聚焦时锁定左右方向键，避免调整后焦点跳到其他控件；Tab 仍可离开。
- 公式示例用当前字体覆盖的积分上下界表示，消除缺字方框。

## 验证范围

Rust 1.96.0，egui/eframe 0.36.2，Linux Xvfb / OpenGL 软件渲染。
7 项测试覆盖默认视图、命令切换、缩放范围、适合宽度到手动缩放，以及实际 egui 输入事件和裁剪边界。
布局尺寸为 640×480、844×1011、1280×900 逻辑像素；可见边界测试不等同于文字重叠检测，后者通过截图人工核对。
无窗口测试主动丢弃字体纹理增量，不验证 GPU；下面的截图来自真实 eframe 窗口。

键盘测试按真实帧序列发送 Ctrl+2、分隔条点击、方向键、Home 与 Ctrl+J。
焦点请求后的稳定帧使 egui 的焦点过滤器生效。
正文及源码仍为静态只读示例，未验证 IME 编辑、编译、保存、读屏或跨平台行为。
主题选择器与偏好持久化仍未实现，保留集中式配色入口。
