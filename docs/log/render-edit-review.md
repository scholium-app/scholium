# 2026-09-25：渲染与编辑评审、延迟基线与改进计划

用户报告两类问题：字体渲染模糊、编辑不跟手（"有时候就几毫秒但是就是很不跟手"），并要求
对照 `../mogan` 的实现评审现有编辑功能、给出改进或重写方案。

## 评审结论（当日代码状态）

保留判断：`scholium-model` / `scholium-document` / `scholium-typst` 的投影与
glyph span → 源码位置映射（`geometry.rs`）是阶段 0 验证过的核心资产，与
[render 模块](../modules/render.md)规范一致，**不推倒**。

问题清单（均附当日的文件行号写入计划文档，此处只留结论）：

- 模糊：固定 2 px/pt 光栅化 + 任意逻辑比例显示 + 线性过滤，常见档位均不清晰；
  正文依赖系统 Times New Roman / SimSun，缺失时静默回退。
- 不跟手：击键字形要等"20ms 去抖 → 全文档重编译 → 采纳 → 整页光栅 → 采纳"两跳流水线；
  期间无乐观渲染，字符不可见；连续击键重置去抖。
- 死区：编译期间几何为空——点击失效、Home/End 跳文档首尾、光标冻结或落在硬编码坐标。
- 模型：页面编辑器光标是全文档拼接串字节偏移，每帧全量重建；`focus_after_*`
  三个启发式字段补偿异步回声；撤销未实现（Ribbon 按钮置灰）。

对 `../mogan`（TeXmacs）只做架构调研、未搬任何源码（硬性约束 1）。吸收的结论：
单一权威树 + 纯投影 box tree、光标用逻辑 path 锚定使重排不漂移、失效粒度=段落、
"装饰路径"区分排版产物与可编辑内容。引以为戒：其光标移动的 2^23 几何试探与
隐式回退链是复杂度失控点，方向键移动应以结构化光标代数为主、几何搜索只留给鼠标。
Mogan 的做法与本项目 `render.md` 已写明的"视觉 caret 权威位置是 TreeCursor"一致——
是实现退化成了字节偏移，不是规范缺失。

## 延迟基线（报告 0045）

新建 `spikes/render-latency/`（独立 workspace，不进正式依赖图），经 `PreviewCompiler`
公开 API 走真实链路，8/64/256 段 × 10 次单字符击键，release 与 debug 各两轮：

- release：击键→字形可见 p95 = 4.2 / 23.4 / 188.8 ms；其中光栅段 p95 仅 2.2–6.8 ms。
- debug：同口径 p95 = 39.2 / 152.7 / 1416.8 ms。
- **主因是全文档重编译，不是光栅化**——推翻了评审时"光栅是隐藏大头"的推断
  （该推断已被写进本日志前一轮对话，以报告 0045 为准）。
- 状态栏自报耗时只含编译段，与端到端口径差 1.1–10 倍。
- "有时候就几毫秒"与"不跟手"并存的双峰体感得到解释：小文档确实几毫秒；
  日常 `cargo run`（debug）+ 稍大文档即到百毫秒~1.4 秒档。
