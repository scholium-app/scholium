# 项目语言、跨格式转换与文件操作

状态：产品方向已由 [ADR 0041](adr/ADR-0041-separate-latex-typst-kernels.md) 确认；LaTeX 实时预览引擎待评估，
见 [LaTeX 工作区计划](plan/LATEX_WORKSPACE.md)。本文取代原《混合源码、团队编辑与文件操作》；原设计
（团队语言切换、ForeignSource 混合与混合构建）见 [ADR 0001](adr/ADR-0001-mixed-source-team-editing.md)、
本文件的 git 历史及阶段 0 报告 0009、0010、0035，已推迟，不再是实现依据。

## 1. 要求

- LaTeX 与 Typst 项目均可打开、编辑、保存、另存为和用于最终输出。
- 每个项目只有一种项目语言，在创建或导入时确定；团队成员编辑同一语言，同语言可多人同时编辑。
- 预览与最终输出使用项目语言的同一引擎，不用另一种语言的引擎代替预览。
- 跨语言只经一次性转换或导出，逐节点报告；不在同一项目内混用或执行另一种语言。

## 2. 三个独立概念

| 概念 | 含义 | 作用范围 |
|---|---|---|
| AuthorityMode | 正文以语义图（仅 Typst 项目）还是源文件为准 | 项目，变更需迁移 |
| ProjectLanguage | Typst 或 LaTeX，决定编辑内核、预览与构建引擎 | 项目，变更需迁移 |
| ExportTarget | 本次源码项目、PDF、HTML 等交付目标 | 单次导出，不改变项目 |

LaTeX 项目另有引擎设置（LuaLaTeX、XeLaTeX、pdfLaTeX），只决定预览路径与构建命令，不是另一种项目语言。
模板与样式属于项目语言：Typst 项目用 Typst 模板，LaTeX 项目用文档类与宏包。

## 3. 项目语言的确定

- **新建**：用户先选项目语言，再选形态与模板。
- **打开 `.typ` / `.tex` 文件**：按入口文件确定项目语言，无元数据也能按原格式编辑；不执行项目命令、
  不自动重写正文。
- **打开目录**：按入口文件确定；同时存在两种语言入口时要求用户选择主入口。另一种语言的文件作为普通
  文本资源保留，可查看并以纯文本编辑，但不参与预览、构建或结构投影；被主入口引用时给出诊断。
- **LaTeX 引擎**：依次取项目设置、`% !TEX program` 魔术注释、`latexmkrc`；无法确定时默认 LuaLaTeX 并在
  状态栏标明。非 LuaLaTeX 项目没有实时段落路径，以后台整编作为预览。

切换项目语言是迁移，不是设置项：见 §5 的跨格式另存为。

## 4. 团队协作

同一项目的所有成员编辑同一语言，经 CRDT 合并；不存在语言控制记录、语言 epoch、源码写许可或切换屏障。
离线编辑与重连按普通协作规则合并（见 [历史与协作](HISTORY_COLLABORATION.md)）。转换产生的新项目拥有新的
项目身份，默认不复制协作成员与权限。

## 5. 跨格式转换

管线：`源 CST → 转换 IR → 目标生成器 → 目标工具链构建与验证`。

- 只展开已声明为纯且安全的宏/函数；其余作为 Raw 保留原文。Raw 在同方言生成时原样输出，跨方言时使用
  用户配置的映射或可见 fallback（Degraded），否则阻止导出。
- 目标项目中不执行源语言：不能原生转换的图表、宏或模板须由用户先在源项目生成图像/PDF 资源再引用，
  或接受报告中的降级。
- 原生结构项目导出 LaTeX 源码使用 generator 子集，属于导出能力；生成结果由 LaTeX 工具链单独验证。
- 转换先写临时目录，验证成功后发布；失败保留原项目与之前的成功产物。

## 6. 文件操作

| 操作 | 明确语义 |
|---|---|
| 打开 `.tex` / `.typ` | 按 §3 确定项目语言后按原格式编辑；不执行项目命令、不自动重写正文 |
| 保存 | 原格式文本最小写回；原生项目保存语义正文与资源；解析失败不阻止草稿落盘 |
| 同格式另存为 | 创建新项目身份与资源路径映射，默认不复制协作身份/权限；历史携带是显式选项 |
| 跨格式另存为 | 按 §5 创建目标入口、资源与转换报告；成功后切换至独立目标项目，原项目保留 |
| 导出源码项目 | 生成目标语言入口及完整资源与报告；不改变当前项目、权威模型或项目语言 |
| 导出 PDF | 使用项目语言的引擎构建并验证最终结果；LaTeX 导出不含实时预览的辅助捕获代码 |

manifest 文件名/序列化格式由持久化 ADR 决定；不能先发明扩展名作为已发布格式。
本地私人草稿默认不进入共享/发布包；参与导出的草稿必须先纳入快照或由用户明确选择已提交正文，
禁止在界面显示新内容时悄悄导出旧版本。

## 7. 报告与验收

每节点报告保真度 Exact/Equivalent/RawPreserved/Degraded/Dropped 与编辑性 NativeEditable/SourceEditable，
另附源位置、丢失属性、依赖与修复建议。报告范围覆盖模板、定义与附件，不能只遍历已成功投影的正文。

必须通过：

1. 打开含两种语言入口的目录时要求选择主入口，另一语言文件不参与构建且被引用时有诊断。
2. 两位成员同时编辑同一项目，CRDT 收敛；离线修改重连后不丢失。
3. Typst ↔ LaTeX 常用论文子集转换后目标工具链构建通过，报告与实际差异一致，无静默 Dropped。
4. 不可转换的宏、模板与绘图被准确标为 Degraded 或阻止导出，原文保留在报告与源项目中。
5. 转换失败注入：原项目与之前的成功产物不受影响。
6. LaTeX 项目的 PDF 导出与普通命令行构建一致；Typst 项目的预览与导出同源。

## 8. 已推迟的能力

以下能力不再是产品要求，阶段 0 证据只作追溯；重新引入任何一项须新立 ADR 并重新验证：

- ForeignSource 混合组件（行内/块/章节/文档级异语言内容）及其作用域、依赖与执行合约；
- 跨引擎宏/函数调用、模板作用域、双向引用与有界多轮构建；
- 标准目标包中的预生成外语资源、可重建混合包；
- 团队语言切换协议：控制记录、edit_epoch、写许可、写集校验、drain 屏障与旧 epoch 拒绝；
- 用 Typst 为 LaTeX 发布目标提供快速预览及双后端差异诊断。
