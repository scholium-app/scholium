# ADR 0026：多块文档会话（段落与标题）

- 状态：Accepted（本地多块结构限定范围）
- 日期：2026-09-23
- 影响模块：scholium-model、scholium-document、scholium-app

## 背景

ADR 0024 的 LocalSession 只维护单个含换行的文本叶子。阶段 1 的主线要求文档先具备
最小结构（段落、heading），存储 schema、Typst 预览、源码生成与撤销都以它为前提。

## 决策

`scholium-model` 的投影从单段文本改为有序块序列：每块有稳定 NodeId、结构种类
（正文、一级标题、二级标题）与不含换行的文本。编辑请求统一为 revision 绑定的
`DocumentRequest`，当前两种：`ReplaceText`（整块替换文本）与 `SetKind`（改块种类）。

`LocalSession::apply` 把 `ReplaceText` 文本中的 `\n` 解释为结构分段：目标块按换行
拆成多个同种类连续块，原块保留身份与首段文本，后续块取新身份。由此会话维持不变式
"存储的块文本永不包含换行"；回车分段不需要独立的 Split 请求。
容量上限为单块 1 MiB、1 万块、10 万动作，越界拒绝且不动文档。

app 侧每个块渲染一个 TextEdit：回车产生的换行经 `ReplaceText` 分段，分段应用后
光标移到尾块起点；块首按 ↑ 到上一块末尾、块尾按 ↓ 到下一块开头（消费按键，
编辑器不再处理）；工具栏段落样式下拉对聚焦块发 `SetKind`，示例工作区保持禁用预览。
拒绝草稿与 IME 预编辑缓冲均按块归属。

仍然不在范围：保存/恢复、块删除与合并（退格跨块）、树容器结构、粗体/强调等行内
格式、数学结构、actor undo、源码生成与 Typst 排版。TextEdit 不因多块而成为结构
编辑器；ADR 0024 的其余边界继续有效。

## 验证

- `scholium-document` 单元测试：换行拆分（含空段与尾换行）、SetKind 保持身份与文本、
  逐块的过期/重复/错目标/容量拒绝均为原子操作、投影不可变更权威。
- `scholium-app` headless 帧测试：新建后输入、回车分段并把焦点移到尾块、工具栏
  SetKind 命中聚焦块、拒绝草稿按块保留、IME 预编辑不产生动作。

## 后续替换门禁

块删除/合并与跨块选区需要显式请求种类与光标语义设计；树容器（章节嵌套）引入前须
对齐 spike 中已验证的 TreeCursor/选区模型；正式存储 schema（见 ADR 0023 门禁 1）
应针对块序列而非本实现的内部 Vec 细节冻结。
