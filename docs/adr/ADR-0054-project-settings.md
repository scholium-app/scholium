# ADR 0054：持锁保存项目设置与入口身份

- 状态：Accepted（T45 项目设置）
- 日期：2026-11-03
- 影响模块：storage、app、latex
- 关联：[ADR 0051](ADR-0051-project-files-and-session-retirement.md)、[存储模块](../modules/storage.md)

## 背景

项目设置需要共享主文件、LaTeX 引擎和参考文献工具。将设置仅保留在 UI 会在重开时丢失；
改写源码 magic comment 会混淆用户正文与项目配置。入口路径可以变化，但其私人草稿和物化记录的资源身份不能随切换丢失。

## 决策

新项目仍创建 ADR 0051 的 v1 声明；第一次显式保存设置在当前 ProjectStore 独占锁下发布 v2 声明。
v2 保留 format、项目 ID、固定语言和 authority，增加可选 engine、默认 Auto 的 bibliography，以及
entry_resources（项目相对入口到稳定资源 ID 的映射）。SQLite schema 和追加历史不变，不迁移正文或历史。
读取支持 v1/v2，拒绝未知版本；v1 不接受 v2 设置字段。旧二进制拒绝 v2，不能忽略设置后冒充成功打开。

`SourceProject::update_settings` 是持锁写入口。切换主文件要求当前输入已保存或显式丢弃，且没有未完成物化意图；
新入口须安全、存在且符合项目语言。离开时保存当前路径与资源身份，返回时复用身份和私人草稿。
目标草稿读取沿用源码打开的崩溃恢复规则：磁盘、草稿与已完成物化 hash 一致时接纳已发布基线。
原生结构项目不提供入口切换；Typst 源码项目不接受 LaTeX 构建选项。

写入前比较磁盘声明与已打开的声明，外部改变时拒绝覆盖。
设置写入同目录独占临时文件并同步，再 rename 覆盖声明并同步元数据目录；失败不宣称成功。
同格式另存为复制构建偏好，但生成新项目及资源身份，不复制私人历史或草稿身份。

显式引擎优先于 magic comment 与自动检测；没有显式选择时沿用原检测。
应用通过 `SourceSession::with_engine` 设置派生预览快照，重建 worker 和页面状态，不改源码或草稿。
参考文献工具目前作为声明偏好保存，实际 bibliography 构建流水线不在本批实现范围。

## 验证与边界

测试覆盖设置重开、语言与项目身份不变、源字节和草稿保留、安全入口拒绝、脏输入拒绝、
资源身份往返、已发布草稿恢复、外部声明冲突，以及另存为保留偏好并分配新身份。
内核测试验证显式引擎覆盖与快照内容、路径和 revision 不变；真实窗口验证设置保存后状态栏跟随。

原子发布承接现有本地 fsync/rename 与项目锁假设；不承诺跨不合作外部写入者的原子 CAS。
目录同步失败可能已留下完整的新声明，错误仍返回失败；重开读取磁盘状态，禁止盲目覆盖。
macOS/Windows 原生持久性和系统选择器仍需后续验收。
