# ADR 0020：原生源码双副本协作实验

- 状态：Accepted（阶段 0 限定实验）
- 日期：2026-09-20
- 前序：ADR 0009、ADR 0016；证据：[报告 0039](../spikes/SPK-0039-native-source-replicas.md)。

## 决策与候选

原团队窗口共享一个 Editor，不能验证真实 CRDT 增量收敛和 actor-local undo。
直接把整份生成源码与 SDG 同时共享会产生两个权威；完整共享语义树则涉及尚未验证的结构并发。
选择显式 `SCHOLIUM_SPIKE_REPLICAS=1` 源码权威实验，在同一原生窗口显示两个独立 LoroDoc，
各有独立 peer id、UndoManager、草稿和基文。该模式不编辑 SDG、不启用实验会话持久化。

采用已选定 Loro 1.16.0（MIT），锁定版本、关闭默认 features。本轮仅允许 16 KiB 内字母数字、
空白和 `-_.` 纯文本片段；拒绝宏/公式/结构语法，不把它当成任意 LaTeX/Typst 协同编辑器。
按 Unicode scalar 下标生成最小替换，未改动文字保留 CRDT 身份；每次应用对应独立撤销检查点。
本地撤销生成新更新，远端 import 不进入本地撤销范围，不使用快照回退。

写入与撤销先经原严格协调器的语言、epoch、许可门禁；成功才进入受信消息队列。
队列最多 128 条、单更新最多 1 MiB，测试可延迟、逆序、重复交付；无外部网络 decoder。
引擎修改/导出/交付错误时停止继续写入，不伪造事务回滚。脏草稿遇到远端更新保留并拒绝覆盖。
语言切换等待已接受队列排空及两端 IME 结束；草稿保持原 epoch，必须显式重新生成。
新 epoch 重置实验撤销管理器，同 epoch 重新生成不丢本地撤销。第三名协调夹具成员没有编辑副本，
由 harness 确认空输入；这是可见的测试假设，不冒充分布式 ACK。

## 后果与替换

两独立文档是同一个源码权威模型的副本；UI 文本框是未提交草稿，已接受正文只从 Loro 读取。
这验证源码片段协作、窗口提交与 IME 控制链路，不关闭共享 SDG、结构 wrap/unwrap、真实网络身份、
断线恢复、历史持久化或恶意 opaque update 校验。生产适配须接 ProjectSession 和正式协议，
替换时重跑同样的乱序/重复、撤销、草稿冲突与语言切换对照。
