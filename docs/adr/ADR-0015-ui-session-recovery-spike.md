# ADR 0015：候选窗口实验会话恢复

- 状态：Accepted（阶段 0 spike）
- 日期：2026-09-19
- 证据：[报告 0031](../spikes/SPK-0031-ui-session-recovery.md)

## 背景与候选

原生 UI 计划要求打开、保存、重开和草稿恢复。生成源码不能完整保存语义结构和独立草稿；
直接序列化 Editor 会固化实验历史实现。本轮选显式实验 DTO，不建设正式项目存储服务。

## 决策

`SCHOLIUM_SPIKE_SESSION` 显式开启单文件试验：启动打开，窗口保存、重开、自动 checkpoint。
保存 SDG 可达树的类型、槽位、文本、变体，以及当前源码语言、草稿、生成基文和过期标记。
预编辑串与渲染产物不保存。读取、验证、重建、序列化、写入和同步由工作线程执行；UI 捕获内容
快照，单个请求在途。500 ms 停顿后保存；临时文件同步、rename、目录同步后才报告持久化。
正常关闭等待当前内容保存，失败可显式放弃。强杀只保证已确认 checkpoint。

同机实例使用旁路文件锁；保存比较上次读取/写入的完整字节，外部变化阻止覆盖。任意外部程序
在最终比较与 rename 间的竞争尚未解决，锁只约束遵守锁的实例。损坏文件不自动修复；
加载期间有新编辑就拒绝旧结果。限制 16 MiB、10 万节点、深度 128，不表示上限均已性能验收。

恢复通过公开语义编辑 API，用外部 actor 重建，不进入本地撤销范围。节点/字符身份和原历史
不延续。过期草稿保留原文与基文，但继续触发 stale 拒绝，不能用重建映射代替原映射提交。
恢复重建两个渲染会话，避免 revision 碰撞采纳旧产物。

## 验证、后果与替换

报告 0031 验证真实窗口保存/重开、SIGKILL、错误和过期草稿、外部冲突、损坏文件与正常关闭；
单元覆盖晚到加载和临时文件失败。未完成断电、慢盘、磁盘满或任意外部写者竞态验收。

`scholium-ui-session-spike-v1` 是可丢弃实验，UI 明示不含历史。没有文件选择器、普通源码项目
打开、多语言草稿集合、资源目录、WAL 或正式迁移。正式实现须接入 ProjectSession/storage，
另立持久化 ADR，不将此 DTO 宣布为产品格式。
