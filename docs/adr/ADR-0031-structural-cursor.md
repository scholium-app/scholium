# ADR 0031：结构光标取代页面编辑器的全局字节偏移

- 状态：Accepted
- 日期：2026-09-26
- 影响模块：scholium-model、scholium-document、scholium-app
- 接续：[ADR 0029](ADR-0029-direct-page-editing.md)、[ADR 0026](ADR-0026-block-document-session.md)
- 依据：[报告 0046](../spikes/SPK-0046-editor-usability-audit.md)（结论 Fail）、
  [E1 实施计划](../plan/E1_STRUCTURAL_CURSOR.md)

## 背景与候选

[ADR 0029](ADR-0029-direct-page-editing.md) 把页面编辑器的坐标定为"全文档拼接
markup 的 UTF-8 字节偏移"，并明确预留了替换条件："须后续替换为正式 TreeCursor/Selection"。
[报告 0046](../spikes/SPK-0046-editor-usability-audit.md) 证明该条件已经到期：
32 项体验契约 19 项失败，其中 8 项是**结构性内容损坏**，3 项是旧几何重定位错误，
1 项是越界 panic（其余为回显与粘贴语义问题）。

本轮在隔离 X11 会话中复现了用户可见后果。`$alpha$` 在公式右缘按回车后，
屏幕上正确的排版 α **消失**，变成字面文本 `$alphatail` 加一个孤立 `$`，
且已写入 SQLite（状态栏显示"已保存 r6"）。`$alpha$` 在公式尾退格后
静默退化为普通文字 `$alpha`。损坏不需要用户确认，直接落盘。

根因是坐标模型，不是缺少边界判断：`$`、`*`、`_` 是**投影语法**，
却被当作正文字符参与回车与删除。给 Enter 加一条判断只能覆盖公式右缘一种情形，
盖不住公式内部回车、边界删除、粗体跨段和真实字形命中后的同一条路径。

候选方案：

- **(a) 保留字节偏移，给各条输入路径补边界判断。** 改动最小，但每加一种结构
  （粗体、强调、后续的槽位）就要重审所有路径；报告 0046 的 8 项分属 4 条路径，
  而根因只有一处。拒绝。
- **(b) 结构光标 + 投影。** 编辑器持有块内结构地址，输入先在结构层形成语义操作，
  再由投影生成 markup。`$`/`*`/`_` 退化为纯输出细节，不参与编辑。**采用。**
- **(c) 完整 TreeCursor 与固定槽位。** `docs/modules/document.md` 的目标态。
  需要 `Inline` 从扁平 `Vec` 升级为带槽位 schema 的节点树（分数 numerator/denominator、
  Script base/sub/sup），并接入 capability 与 invariant 校验。
  这是正确的终点，但超出阶段 1 的最小编辑闭环，且会把本 ADR 变成一次数据模型迁移。暂缓。

## 决策

引入三层坐标，各司其职，禁止互相替代：

| 层 | 表示 | 用途 |
|---|---|---|
| 语义位置 | `BlockPosition` / 结构地址 | 编辑请求、选区、撤销记录 |
| 投影字节 | 拼接 markup 的 UTF-8 byte offset | 仅在与 `BlockEdit` 互转时临时构造 |
| 页面几何 | revision 绑定的字形矩形 | 命中测试与绘制，不驱动编辑请求 |

`scholium-app` 的 `page_editor` 新增 `Caret`：块 ID + 块内结构地址 + 方向。
`EditorState` 不再长期持有全局字节偏移。输入先在结构层求值为编辑命令，
再投影成 `BlockEdit`；不存在"先拼坏字符串、再由解析器猜回结构"的路径。

`BlockPosition` 保留在 `scholium-model`，仍是 `BlockEdit` 的公开坐标；
本决策只改变**编辑器持有的状态**，不改 `BlockEdit` 的线格式，
因此不构成数据兼容性变更。

### 结构编辑语义（报告 0046 未定义、本 ADR 固定）

报告 0046 只断言"结构不得被破坏"，未定义边界行为的期望结果。为使实现与测试有唯一解，
固定如下语义：

| 操作 | 语义 | 理由 |
|---|---|---|
| 公式**右缘**回车 | 公式完整保留，新块在公式之后 | 光标在公式末，与文末回车同构 |
| 公式**内部**回车 | **拆成两个公式**：`$ab\|cd$` → `$ab$` 与 `$cd$` | 见下 |
| 公式**尾退格** | 删除公式内容；公式变空则删除结构，**不**删定界符 | 退格删除的是用户可见的字符，定界符不可见 |
| 公式**首 Delete** | 与尾退格方向对称 | 同上 |
| 粗体内部回车 | 格式跨段延续：`*ab\|cd*` → `*ab*` 与 `*cd*` | 与用户在粗体中间按回车的预期一致 |

**公式内部回车选"拆成两个公式"而非"整块拆块"**：整块拆块会让公式标记跨越段落边界，
生成 `Inline::Math` 里含 `\n` 的源串或跨块的半个公式，两者都要引入新的表示。
拆成两个公式在结构层是局部操作，且与粗体的处理同构（一个格式节点拆成两个同型节点），
实现与测试都能共用一条路径。

### 几何的 revision 归属

每份命中几何记录产生它的 revision。旧坐标只经**从该 revision 起**的变更链转换一次。
映射不可靠时（命中已被删除的端点，或跨了结构边界）返回"无法定位"：
**不得**落到其他段落继续写入，也不得用旧坐标构造编辑请求。
这是[区域计划](../plan/RENDER_EDIT_REWORK.md) E2 的剩余判据，并入 E1 实现。

### 回显层

`optimistic_line` 不得把规范 markup 直接交给文本布局（报告 0046 的 b02/b03：
页面显示 `$alpha$`、`*bold*`）。过渡回显必须按结构投影，画当前外观而非标记字符。
其几何不得依赖旧行字形，因此空文档与新段落同样有即时反馈（b04/b05）。

## 验证方法

沿用[报告 0046](../spikes/SPK-0046-editor-usability-audit.md)建立的验收口径，不新建一套：

```bash
python3 scripts/audit-editor.py --native
```

- 单元与契约：`crates/scholium-app/src/session/usability_audit/` 的 32 项契约，
  加上 `page_editor/tests.rs` 的常规回归。`Caret` 三种表示的双向转换有往返一致性测试。
- 结构语义：上表每一行一个正向断言，外加"结果中不存在含 `$`/`*` 的 `Inline::Text`"的负向断言——
  这正是报告 0046 识别实际后果的口径。
- 崩溃：b13（同帧点击与键入越界）另加**常规**（非 opt-in）回归测试，
  崩溃修复不能只由审计套件覆盖。
- 原生窗口：隔离 X11 会话中 8 个场景，断言真实截图与 SQLite 语义快照。

退出条件：**除 `a07` 外**的契约全部通过（`a07` 见下"规范冲突登记项"）、8 个原生场景全通过、
`cargo test --workspace` 无回归，fmt/clippy/规模/rustdoc 全绿。
即目标为 **31/32 契约 + 8/8 原生**——不是 32/32，因为 `a07` 的取舍由体验规范 §9 决定，不在本 ADR 内关闭。

**规范冲突登记项（`a07`）**：`a07`（粘贴普通标点必须等于逐字键入）与
[体验规范 §9 多格式粘贴](../EXPERIENCE.md)冲突——§9 要求"普通粘贴**优先使用剪贴板的
HTML/MathML 等结构格式**，退化到纯文本"。结构感知粘贴是规范要求的行为，
故 `a07` 维持 FAILED 作为**已登记的规范冲突**，不做 expected-failure 豁免，
也不为它牺牲内容完整性。§9 尚未实现的其余部分（结构格式读取、"粘贴为"、源码预览）
属阶段 3 格式交换范围。

**实施进展**：**E1 六步全部完成**，见[报告 0048](../spikes/SPK-0048-e1-structural-cursor.md)：
体验契约 13/32 → **31/32**、原生窗口 4/8 → **8/8**，全程**零回归**；
`cargo test --workspace` 81 → 111 passed / 0 failed；五门禁全绿。

S2 曾由独立验证者核验（[报告 0047](../spikes/SPK-0047-structural-cursor-verification.md)）：
在基线 `59eca0c` 新建 worktree 重跑得 13/19，与报告 0046 逐用例一致，确认零回归、零判据篡改。
b13 的常规回归测试缺口已在 S4 关闭。

剩余未覆盖见报告 0048「失败与不确定性」：真实 IME/跨平台验收、撤销非协作历史、
公式仍为源串而无槽位结构。

## 后果与替换条件

编辑器的坐标不再随文档增长而失效，`$`/`*`/`_` 不再可被拆坏，保存内容与用户所见一致。
代价是 `page_editor` 增加一层结构与投影转换，并需要维护结构地址到投影字节的映射。

未解决：`Inline` 仍是扁平 `Vec`，因此"公式内部"没有比行内序号更细的结构，
分数/上下标的槽位导航仍不可用。本决策不宣称数学结构编辑完成；
升级到候选 (c) 时需新立 ADR 并做数据模型迁移。

报告 0046 的失败证据保留作修复溯源，不改写其 Fail 结论；
E1 完成后的判定记在**新报告**而非覆写 0046（[spikes 规则](../spikes/README.md)）。
本决策不改权威模型、不加第二可写副本，不改变 `BlockEdit` 线格式，
不涉及 CRDT 或共享历史（[硬性约束 2/3/4](../../AGENT.md)）。
