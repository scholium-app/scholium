# ADR 0024：基础段落接入的临时边界

- 状态：Accepted（本地基础接入限定范围）
- 背景：用户要求先合并应用壳 PR，再开始基础接入。

## 决策

`scholium-model` 定义随机 128 位文档/节点/请求身份、revision 与投影请求；
`scholium-document::LocalSession` 暂时维护单个含换行的文本叶子及只追加的请求元数据。
app 的 SessionBridge 串行协调请求，UI 仅持有投影、待发请求和被拒绝的本地草稿。
这是可执行的单用户内存接入，不是正式 shared SDG adapter；其公开 API 是临时、非稳定接口。
正式文档 patch 仍须经 collab transaction adapter，不能把此处的直接替换推广到共享树。

新增文档从“文件 → 新建”或 Ctrl+N 进入。输入控件的预编辑缓冲不产生正文 Action，提交后才进入会话。
内部 TextEdit 的键盘撤销被屏蔽，不能冒充 actor undo；菜单与工具栏撤销保持禁用。
Action 目前只记录请求与版本元数据，不具备补偿、持久历史或协作语义。

保存、恢复、标题/数学结构、文件导入、源码生成与 Typst 排版不在本次范围。
新建或关闭现有内存文档必须明确确认丢弃；状态始终显示未保存。
源码模式对真实内存文档显示未接入提示，不能继续展示另一篇静态示例。
示例工作区仍可在启动时查看，但不属于新建文档的权威内容。

## 后续替换门禁

依据 ADR 0023，正式存储前比较 SQLite/rusqlite 与 redb 并裁决 schema；
共享树接入前验证稳定节点、并发结构和 actor undo；源码理解前确定 parser。
本次不关闭这些门禁，也不以普通 TextEdit 宣称已实现所见即所得结构编辑。
新依赖 uuid 使用 v4，仅用于当前内存身份；不冻结序列化格式。
