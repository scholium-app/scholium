# ADR 0013：左侧编辑器使用 Typst 图像与同源交互几何

- 状态：Accepted（阶段 0 spike 范围）
- 日期：2026-09-18
- 依据：用户明确要求替换左侧拼接渲染；执行者 Codex
- 证据：[报告 0027](../spikes/SPK-0027-structured-typst-frame-research.md)、[报告 0028](../spikes/SPK-0028-typst-editor.md)

## 背景与候选方案

继续调节 core 自绘常数无法获得 Typst 的数学排版；仅覆盖整页图片会留下错误的光标、命中与选区。
独立重写数学引擎成本高，ReX 暂不满足成熟度要求。已有 Typst 0.15.1 Frame 可提供图像和源 span 几何。

## 决策

桌面默认使用隔离 Typst helper，一次编译导出 PNG 与 glyph/shape/source-span JSON。
后台队列仅保留最新请求，主线程只接受匹配当前 SDG revision 的结果，图片、几何原子更新。
UI 不链接编译器；helper 仍经过 ADR 0012 的 OS 沙箱、资源限制与运行时白名单。
编辑 helper 使用受信调用方选定的 `typst-editor` 运行时清单，仅提供 helper、所需动态库、
prlimit 和字体资源；其它工具链默认仍用原清单。缩小挂载集合不改变隔离方式、超时或资源上限。

source span 通过只读编辑投影映射到 NodeId/UTF-8 byte 或空槽位 Cursor；光标、命中、
选区、IME 锚点与 AccessKit 使用同一批几何。过期画面可以保留，但不提供旧坐标点击或光标。
连续键盘编辑仍作用于当前语义光标，不等待编译。左右显示共用此投影；Source Studio 的可写
源码投影依然由 reconcile 管理，两者均非权威模型。

数学字符串用 `#text(...)` 保留可追踪 span。空编辑槽位使用不绘制内容的 box 和可定位 metadata，
由编译位置恢复命中和光标框，不显示方框字形，也不写入 SDG 或发布源码。
当前单色编辑投影输出透明背景和白色前景，由 UI 按主题文字色着色；这不代表支持任意彩色内容。
矩阵沿现有 spike 的两列语义输出行分隔，尾行空位只做显示补齐。

## 验证方法与后果

报告 0027 已核对场景重绘与 Typst 参考图。报告 0028 增加沙箱编译映射测试和真实窗口中文输入、
数学编辑、拖选、整节点选区、撤销与 Unicode 验证。旧同步布局测试使用显式 `new_layout_probe`，
不作为新后端验收证据。

该实现每次请求启动编译子进程，尚未接持久 World，输入到图像更新存在延迟；固定页面宽度，
部分复杂文本映射、结构变体和完整共同清单仍未关闭。遇到不支持的 frame（图像、链接、裁剪、
变换）失败并显示状态，不猜测几何。不升级阶段 0。

## 替换条件

后续持久会话与局部纹理上传已由 [ADR 0014](ADR-0014-resident-typst-editor.md)细化；
本 ADR 的同 revision 图像/几何合约继续有效。

后续可在同样的 revision 与 source-map 合约下接持久隔离 worker、瓦片或矢量场景。
必须重新验证视觉和真实编辑交互，不能以旧布局回退掩盖失败。
