# ADR 0021：原生源码视口与无障碍依赖补丁

- 状态：Accepted（阶段 0 Linux 实验）
- 日期：2026-09-20；执行负责人：Codex
- 前序：ADR 0006；验证报告：SPK-0040（本轮验收）。

十万行源码在真实窗口中需要独立滚动区域，不能只通过 headless 的文本修改断言。
源码草稿保留在原有缓冲区，滚动不创建第二份权威文档；应用和丢弃草稿按钮留在视口外。
无障碍源码控件显式提供语言和名称。发布构建与调试构建分别报告，不把测试脚本等待时间当作输入延迟。

锁定 egui 0.36.2 和 accesskit_atspi_common 0.18.1，并通过 Cargo path patch 使用
仓库内可审查副本，不修改全局 Cargo cache。两者仍为 MIT OR Apache-2.0；保留上游版权及
AccessKit 的 Chromium BSD 声明、许可证与原始版本信息，来源和最小差异见 vendor/README.md。

egui 的 TextRun 保留原节点 ID、全文、字符下标与字符度量，以透明父节点承载整体变换；
滚动时行坐标保持局部坐标，避免全部行的全局 bounds 一起变化。不能通过删掉屏外文本来冒充无障碍支持。
AccessKit 的 Enabled/Sensitive 依据 disabled 标志独立判断，不再把不支持 ReadOnly 的禁用按钮报为可用。

上游副本保留文件组织便于逐版本审查；项目自行编写的改动仍保持小函数和独立回归。
升级时先检查上游是否修复，再移除对应 patch 并重跑文本/选区/Unicode、禁用动作、滚动坐标与 Orca 验收。
本决策不宣布任意规模不卡顿，也不把基本 Orca 焦点/文本验收等同于完整数学导航读屏。
