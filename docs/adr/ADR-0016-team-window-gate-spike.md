# ADR 0016：团队语言门禁的候选窗口适配

- 状态：Accepted（阶段 0 模拟范围）
- 日期：2026-09-19
- 证据：[报告 0032](../spikes/SPK-0032-team-window-gate.md)

## 背景与候选

原语言协调 spike 只有内存模型测试，候选窗口的语言按钮仅选择本地投影。
单纯禁用按钮不能验证提交门禁；直接建设网络服务超出当前窗口验证范围。
选择导出现有严格协调器的窄窗口接口，在单窗口模拟 Alice/Bob/Carol 三个成员。

## 决策

`SCHOLIUM_SPIKE_TEAM=1` 启用，默认窗口行为不变。三个成员共用同一权威正文和协调器，
各自保留 Session、可见源码与草稿 epoch；成员切换不覆盖私有草稿。控制区明确标记模拟。
源码视图选择与团队语言切换分开；非活动语言可留本地草稿，提交由协调器拒绝。

切换显式请求、逐成员确认、完成，绝不自动伪造远端确认或强制隔离。新提交在屏障期间冻结；
此适配同步处理提交，没有在途网络包。旧 epoch 草稿在重新获取许可后依旧过期，必须显式
丢弃/重建当前草稿才能进入新 epoch，不偷偷重新标记草稿。

提交在私有协调器/正文/源码候选上依次通过既有许可、语言、epoch、写集和 reconcile 检查，
全部成功后同时替换当前状态；失败不产生已接受回执，也不变更正文，原草稿保留。
这只是单 UI 线程的原子发布，不代表服务器数据库事务或网络 ACK 持久性。

本轮正文结构编辑在团队模式只读，避免未接入的直接输入/撤销绕过实验门禁。
普通模式仍可编辑。团队模式不启用实验会话恢复文件：该文件缺少三成员与控制状态，不能伪装
保存了团队会话。UI 切换成员是实验选择器，不是身份认证。

## 验证与后果

报告 0032 验证真实窗口三成员顺序提交、草稿保持、模拟离线、确认缺失、旧草稿和异语言拒绝，
原 60 个协调器夹具继续通过。模型仍不是 CRDT 引擎，源码内容写集验证仍为原字符串抽检。
本轮不关闭真实网络、多进程、协作撤销、跨语言 IME 屏障、团队持久化或完整共同验收。

## 替换

后续接 ProjectSession 与真实协调服务，使用身份/许可协议和共享 CRDT；不能将本模拟身份切换、
克隆状态事务或单窗口串行提交当作生产协作架构。正式边界仍遵循 ADR 0001 与模块合约。
