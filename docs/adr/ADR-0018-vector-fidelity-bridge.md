# ADR 0018：显式语义转换与矢量布局/链接桥接

- 状态：Accepted（Linux 阶段 0、锁定工具链范围）
- 日期：2026-09-19
- 证据：[报告 0035](../spikes/SPK-0035-vector-fidelity.md)

## 决策

`Convert` 明确表示从已有语义 IR 投影到宿主源码；不把它称为外语视觉保真，也不把外语源码
自动解析成 IR。`Include` 保持同语言语义；`Vector` 必须由源引擎生成 PDF，不能偷偷转换公式。
这修正了 `196b7db` 将 Inline + Vector 实际作为宿主公式生成的桥接语义错误。

行内矢量用源引擎的紧致单行框，传递宽、高、下沉量。TeX pt 转 PDF bp 按 72/72.27；
Typst pt 即 PDF bp。Typst 使用字形 bounds 上下边界，避免默认字体行高裁掉深分母和根号。
宿主使用源尺寸并按实际下沉量对齐；块级图仍按宿主宽度缩放。

选择 MIT 许可的纯 Rust `lopdf = 0.38.0`（关闭默认特性）读取单页 PDF 的命名目标和 Link 注释。
解析器只在受信 driver 的 `--vector-worker` 子进程内运行，沿用 pdf-probe 清单、清空环境、
只读输入、独立输出、无网络、10 秒墙钟、4 GiB 地址空间与 64 MiB 文件边界；不在 UI/构建协调器解析 PDF。
新增依赖没有 C ABI 或原生代码所有权边界。worker JSON 为实验派生物，不是正式存储格式。

保留原 PDF 的绘制内容，通过生成宿主源码覆盖层重建链接矩形与目的地。内部 XYZ 目标、跨组件引用和
HTTP(S) 链接在最终件中有效。XeLaTeX 用显式 xdvipdfmx 注释，避免空 hyperref 框被删除；
Typst 0.15.1 的 PDF 导出固有 10pt 目标偏移须抵消，不能把该偏移重复施加到导入坐标。
这些源码覆盖层随标准包交付，标准包仍只需要目标工具链。

## 限制与替换条件

限定零原点、无旋转/裁剪、单页载体，每个组件在宿主源码空间放置一次；矢量内嵌套/重复放置必须显式拒绝。
非 Link 注释、Launch/JavaScript 等动作、未知 URI、非 XYZ 或跨页目的地不静默丢弃，阻止正式输出。
批注、表单、附件和任意 PDF 扩展应另开能力验证，不能从“链接注释支持”推出它们也受支持。
行内数学不声明编号或页码引用目标，引用这类标签必须拒绝，不能发布 `?`。

矢量导入不保留完整 PDF 结构标签、数学语音或阅读顺序；`Convert` 保留可生成的宿主结构，但不构成
PDF/UA 验收。完整无障碍仍按原生编辑器与导出能力各自验证，不归入本次视觉/链接通过声明。
更换 Typst/TeX/解析器版本，必须重跑基线、裁剪、矩形、同页精确目标、拒绝矩阵和干净包重建。
