# SPK-0067：编辑面按显示分辨率栅格（正文发虚）

- 日期：2026-10-12；结论：**Partial**（清晰度与几何一致性已证；3 页文档在 scale 2 显示器上的逐键成本超出停止线，见“性能”，待协调者裁决）。
- 对应：[P1 排版工作区规划](../plan/P1_UI.md)的页面编辑；不改变阶段 0 判定。
- 基线：main `fc31bce`；分支 `ation_ciger/fix/sharp-raster`。

## 复现与根因

编辑面以固定 `RASTER_PX_PER_PT = 2.0` 栅格整页，再由 egui 用 `TextureOptions::LINEAR` 拉伸到页面矩形。
fit-width、逻辑宽 1280、缩放因子 1.5 时页面实际以约 3 物理 px/pt 显示，2 px/pt 位图被放大 1.5 倍；
页面矩形还落在分数物理像素上，又多一次重采样。固定常数不是修复（协调者实验：临时改 3.0 才清晰）。

## 改动

- **分辨率跟随显示。** 目标 `px_per_pt = 页面物理像素宽 / 页宽 pt`；页宽量化为整数物理像素
  （`typst_editor/raster.rs::fit`），因此亚像素抖动不改变目标，且显示宽度与位图宽度严格相等。
  placement 的 scale 取量化后的值，命中、caret、选区、IME 与公式淡色底仍共用同一个 placement。
- **像素吸附。** 页面原点四舍五入到物理像素网格；位图按条带 1:1 采样绘制，条带边取吸附后的同一条边（无缝）。
  快照/过期纹理（目标变了但尚未重栅格）按同一公式拉伸，条带仍首尾相接。
- **去抖重栅格。** worker 保留最新已排版页面，`rerender(RasterSpec)` 只重新栅格、不重新排版；
  缩放、窗口拖拽、缩放因子变化期间继续显示旧纹理，目标稳定约 120 ms 后才请求。键入提交的排版直接
  按当前目标栅格，不等待重栅格；排队的排版先于重栅格执行。
- **纹理与预算。** 位图按 `min(max_texture_side, 4096)` 行切条带；页宽不超过 `max_texture_side`；
  整页不超过 **64 MP**（256 MB RGBA），超出时退回受限倍率（略软，不失败）。
- **A4 预览**（源码模式）按窗格显示物理宽请求页面栅格，吸附与去抖规则相同；A4 页面高宽恒小于单张纹理上限
  （倍率上限为 `min(max_side, 4096)/841.89` 并夹在编译器的 0.25–8 范围内），故预览不分条带。
- 测试专用环境变量 `SCHOLIUM_RASTER_PX_PER_PT`（强制旧的固定倍率，供窗口检查比较锐度）。
- AUDIT 新增 `raster`：位图 `px_per_pt`/宽高/条带数、期望倍率、`pixels_per_point`、页面显示物理宽与原点。

## 性能

`cargo run --release -p scholium-typst --features editor --example typst-main-raster-bench`
（`spikes/typst-main-editor/raster-bench.rs`）：每次提交追加一个字符，测提交到结果的墙钟时间，
每格 100 次键入，三次独立运行取各次的中位数/p95。机器当时有其他编译负载（load ≈ 14，20 核），数字偏噪，
但倍率关系稳定。2.0 px/pt 即旧行为（栅格代码路径相同，仅多一次按条带切分的拷贝）；3.0 对应 scale 1.5 的 1280 逻辑宽，
4.0 对应 scale 2 的 1280 逻辑宽。

| 文档 | px/pt | 中位数 ms（三次） | p95 ms（三次） | 其中栅格中位数 ms |
| --- | --- | --- | --- | --- |
| 1 页（627 pt） | 2.0（前） | 6.5 / 5.9 / 4.9 | 12.5 / 8.4 / 8.1 | 2–3 |
| 1 页 | 3.0 | 12.7 / 10.6 / 7.8 | 19.2 / 13.2 / 13.0 | 5–8 |
| 1 页 | 4.0 | 18.0 / 14.5 / 13.6 | 25.5 / 22.8 / 16.6 | 10–13 |
| 3 页（2119 pt） | 2.0（前） | 15.5 / 13.9 / 13.7 | 27.3 / 24.4 / 23.4 | 8–11 |
| 3 页 | 3.0 | 26.1 / 28.0 / 31.2 | 38.8 / 41.1 / 49.1 | 22–27 |
| 3 页 | 4.0 | 79.8 / 61.4 / 71.4 | 97.5 / 71.0 / 109.4 | 57–73 |

停止线（release、3 页：p95 增长超过 2× 或超过 50 ms）：scale 1.5（3.0 px/pt）p95 为 1.6–2.1× 且最差一次 49.1 ms，
处于边缘；scale 2（4.0 px/pt）p95 为 71–109 ms、约 3–4×，**越线**。栅格耗时随像素数超线性增长
（4.0 比 2.0 多 4× 像素，栅格 ≈ 7×）。按任务规定未继续扩大范围，本 PR 以 draft 提交。
可选的下一步（均不在本范围内）：只栅格视口附近的条带（条带结构已就绪）、多线程并行渲染各条带、
限制编辑中栅格倍率并在空闲后补高分辨率。
