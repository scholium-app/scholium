# SPK-0067：编辑面按显示分辨率栅格（正文发虚）

- 日期：2026-10-12；结论：**Pass**（清晰度、几何一致与逐键/滚动成本均达标；仍随文档长度增长的只有排版本身与 ≤1 px/pt 的底图）。
- 对应：[P1 排版工作区规划](../plan/P1_UI.md)的页面编辑；不改变阶段 0 判定。
- 基线：main `fc31bce`；分支 `ation_ciger/fix/sharp-raster`。

## 复现与根因

编辑面以固定 `RASTER_PX_PER_PT = 2.0` 栅格整页，再由 egui 用 `TextureOptions::LINEAR` 拉伸到页面矩形。
fit-width、逻辑宽 1280、缩放因子 1.5 时页面实际以约 3 物理 px/pt 显示，2 px/pt 位图被放大 1.5 倍；
页面矩形还落在分数物理像素上，又多一次重采样。固定常数不是修复（协调者实验：临时改 3.0 才清晰）。

## 第一版与它的问题

第一版把整页按显示倍率一次栅格（任务书决定 1–4 的单层实现）。清晰度达标，但每次键入栅格整篇文档，
延迟随文档长度增长：3 页文档 release 逐键 p95，2.0 px/pt（旧）23–27 ms；3.0 px/pt（scale 1.5）39–49 ms；
4.0 px/pt（scale 2）71–109 ms（约 3–4×），触发停止线。协调者裁决：**可见窗口条带 + 廉价底图**。

## 改动

- **目标分辨率与吸附**（未变）：页宽量化为整数物理像素，显示宽度与位图宽度严格相等；页面原点吸附到物理像素网格；
  命中、caret、选区、IME 与公式淡色底共用同一 placement；缩放/拖拽/缩放因子变化经约 120 ms 去抖后才重栅格。
- **两层纹理。** `base`：整页、倍率 ≤ 1 px/pt（64 MP 与页宽上限仅作安全网），拉伸绘制，只在新露出的条带尚未渲染时可见。
  `sharp`：显示分辨率下固定 **512 行**（`SHARP_STRIP_PX`）的条带，只覆盖可见范围，1:1 画在底图之上，边吸附后无缝。
- **键入路径。** 排版后只栅格底图和与可见范围相交的条带（Scene 内交付）；上下各一个视口高度的边距条带随后逐条交付，
  新排版或新视图到达时让路。永远不按目标倍率栅格整页。
- **滚动/缩放。** 应用在可见范围（pt）变化时以 ≈40 ms 节流调用 `set_view`；worker 用保留的已排版页面补渲染缺失条带
  （可见的先渲染，再由近及远），不重新排版；条带按 Scene stamp 归属，采纳新 Scene 即整体替换，旧 Scene 的条带
  不会画在新底图上；窗口外（三个视口）的纹理与 worker 记录一并清除。新倍率的条带覆盖可见范围后才替换旧集合。
- **条带渲染不付整页代价。** 帧项按条带包围盒裁剪后平移到条带大小的像素图渲染。
- A4 预览（源码模式）按窗格显示物理宽请求页面栅格；A4 页面恒小于单张纹理上限，不分条带。
- 测试专用环境变量 `SCHOLIUM_RASTER_PX_PER_PT`（强制旧倍率）；AUDIT `raster` 含底图/条带倍率、条带数、可见条带是否齐备。

### 裁剪的发现

typst-render **不**按边界跳过项目：对整页帧渲染一个条带大小的像素图，每个字形仍要处理。release、4 px/pt、
中间条带：1 页文档 1.30 ms，3 页文档 **2.90 ms**（不裁剪，随页长增长）；裁剪后 1.31 / **1.49 ms**（基本与页长无关）；
整页渲染分别为 7.0 / 36.7 ms。裁剪保守：文字按字号估计包围盒（上 1.6 em、下 0.8 em）、形状按 `bbox(true)`、图片按尺寸，
恒等变换的 Group 递归，带变换的 Group 整体保留，另加 2 pt 余量。
正确性：每个条带与整页渲染的对应行逐像素比较，最多相差 1 个最低有效位（测试覆盖 2.0 / 3.0003 / 4.1 px/pt、含末尾不满条带）；
2 px/pt 钉住路径的整页条带拼接与独立 stock Typst 渲染**逐字节相等**（4/4）。

## 性能

`cargo run --release -p scholium-typst --features editor --example typst-main-raster-bench`
（`spikes/typst-main-editor/raster-bench.rs`）。同一会话三次独立运行（机器同时有其他编译作业，load 6.7–8.6 / 20 核），
每格 100 次键入，在文档末尾追加字符，可见范围随光标取页面最后 450 pt（900 逻辑 px / 2 逻辑 px 每 pt）。
“旧”= 每次键入整页 2.0 px/pt（同一会话重测；比第一版记录略慢，因含底图与条带切分）。
3.0 对应 scale 1.5、4.0 对应 scale 2（均为 1280 逻辑宽）。单元 ms，三次运行依次列出。

| 文档 | 模式 | 中位数 | p95 |
| --- | --- | --- | --- |
| 1 页（627 pt） | 整页 2.0（旧） | 7.7 / 5.8 / 7.5 | 12.9 / 11.4 / 12.6 |
| 1 页 | 仅排版 + 底图 | 4.5 / 3.0 / 3.3 | 7.7 / 8.7 / 8.5 |
| 1 页 | 可见条带 3.0 | 11.2 / 10.8 / 11.2 | 16.0 / 14.9 / 19.1 |
| 1 页 | 可见条带 4.0 | 19.4 / 20.2 / 19.6 | 24.4 / 26.5 / 27.8 |
| 3 页（2119 pt） | 整页 2.0（旧） | 27.2 / 26.3 / 27.1 | 34.4 / 34.0 / 31.0 |
| 3 页 | 仅排版 + 底图 | 13.1 / 12.4 / 13.2 | 17.7 / 16.3 / 16.2 |
| 3 页 | 可见条带 3.0 | 24.1 / 23.6 / 21.4 | **31.9 / 28.9 / 29.1** |

验收：3 页文档 3.0 与 4.0 px/pt 的 p95 均 ≤ 旧基线 p95 的 1.5×（旧 31–34 ms → 上限 46–52 ms；实测 29–32、33–35，即 0.9–1.1×），
且均 ≤ 40 ms。第一版同条件为 39–49 / 71–109 ms。1 页与 3 页：条带部分基本持平（同一倍率下栅格耗时 3.0：7 对 14–16 ms 含底图，
单条带 ≈1.3–1.5 ms 与页长无关）；整体仍差约 10 ms，来自排版本身（仅排版 + 底图 3 ms 对 13 ms，其中底图约 7 ms，
随字形数增长）——这部分是剩余的 O(文档长度)，不属于条带。

滚动到未渲染区域（3 页文档，在顶部与底部间来回 40 次；worker 内从 `set_view` 到条带交付，不含唤醒与 UI 上传）：

| 4.0 | 4 | 2.2–2.7 / ≤5.9 ms | 7.0–9.5 / ≤19.7 ms |
