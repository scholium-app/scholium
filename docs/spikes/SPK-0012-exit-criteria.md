## 当前判定

| # | 出口条件 | 判定 | 证据与剩余边界 |
|---|---|---|---|
| 1 | 原生候选共同验收、锁定版本与平台 | **部分满足** | [0023](SPK-0023-native-layout-preview.md) 补整节点选区、AT-SPI 映射和多页翻页/缩放/段落定位的真实窗口证据；首轮 IME/焦点异常保留，定向复测通过。真实字体几何、完整结构反馈、大源码、完整无障碍及团队/文件恢复集成仍未闭合 |
| 2 | 无 npm/Node/WebView、原生依赖登记、许可门禁 | **满足（既定范围）** | 12 个 workspace 的 licenses/bans/sources 全过；原生依赖登记保留。advisories 未跑，不能据此声称无漏洞 |
| 3 | 预览后台编译期间编辑/导航可用、旧 revision 不闪回；性能按声明规模实测 | **部分满足** | [0023](SPK-0023-native-layout-preview.md) 的 256 段/20 页 release 窗口 CPU 组内 p95 为 7.608–9.126 ms，编译加栅格化 2154 ms；翻页/缩放/段落定位通过。尚缺端到端输入与 GPU 呈现测量，不以固定帧毫秒门槛判定 |
| 4 | 受支持源码 round-trip、Raw 不丢失 | **满足（限定范围）** | 两方言原夹具通过；新增事务会话拒绝过期/多行不可归因修改，整份草稿往返校验；不支持任意结构重构 |
| 5 | 两端收敛、本地撤销保留远端输入 | **满足（机制）** | 自研赛马 136 用例；Loro 1.16.0 已选定。树语义边界与产品集成未覆盖 |
| 6 | 不可信源码不能执行外部命令或读取项目根外文件 | **部分满足** | Linux 沙箱良性编译、越界读写、shell/超时/单文件护栏均通过；存在项目根外只读运行时挂载例外，尚需明确白名单及所有入口的覆盖 |
| 7 | 单一可写语言、隔离输入可恢复、旧 epoch 不回灌 | **满足（内存模型 + 恢复机制）** | 语言协调 60/60；真实网络、多进程、fsync 与解析器未验证 |
| 8 | 六类混用成功/失败夹具与支持矩阵 | **部分满足** | 混合构建 36/36，两宿主与三类支持矩阵；行内嵌入、组件内部符号/链接保真仍缺 |
| 9 | 两宿主引用/页码/链接、反馈有界、失败不发布 | **满足（夹具范围）** | 振荡第 3 轮停止、不发布；链接验证到宿主交付件内页级，不含组件内部符号级链接 |
| 10 | 标准包/混合重建包在声明干净环境构建，不支持组合准确阻断 | **满足（实验包范围）** | 28/28 隔离重建，两宿主缺组件对照通过；混合包依赖 spike driver 与权威快照，非正式文件格式或任意源码编辑后重建能力 |

“满足”均指报告声明的机制/夹具范围，不代表对应产品能力完成。
第 3 条按“不阻塞 UI 帧”判定，**不再把编译完成耗时直接等同于 UI 帧耗时**；
仍需真实窗口证据才能关闭。第 6 条保留原要求，不能因添加运行时挂载就默认满足字面上的项目根限制。
