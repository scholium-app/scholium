## 当前判定

| # | 出口条件 | 判定 | 证据与剩余边界 |
|---|---|---|---|
| 1 | 原生候选共同验收、锁定版本与平台 | **部分满足** | [0030](SPK-0030-editing-regression.md) 常用编辑与 26 页编辑、[0031](SPK-0031-ui-session-recovery.md) 实验恢复、[0032](SPK-0032-team-window-gate.md) 三成员窗口门禁模拟通过。完整屏幕阅读器、真实团队协作/撤销与正式项目恢复仍缺；10 万行只有 headless 测量 |
| 2 | 无 npm/Node/WebView、原生依赖登记、许可门禁 | **满足（既定范围）** | 12 个 workspace 的 licenses/bans/sources 全过；原生依赖登记保留。advisories 未跑，不能据此声称无漏洞 |
| 3 | 预览后台编译期间编辑/导航可用、旧 revision 不闪回；性能按声明规模实测 | **满足（已测夹具）** | [0030](SPK-0030-editing-regression.md) 标准连续输入、256 段/26 页编辑、翻页/缩放/定位及后台旧结果门通过，CPU/后台耗时有原始记录。用户接受当前体感，停止精细优化；未宣称任意规模或 GPU 呈现时延保证 |
| 4 | 受支持源码 round-trip、Raw 不丢失 | **满足（限定范围）** | 两方言原夹具通过；新增事务会话拒绝过期/多行不可归因修改，整份草稿往返校验；不支持任意结构重构 |
| 5 | 两端收敛、本地撤销保留远端输入 | **满足（机制）** | 自研赛马 136 用例；Loro 1.16.0 已选定。树语义边界与产品集成未覆盖 |
| 6 | 不可信源码不能执行外部命令或读取项目根外文件 | **部分满足** | [0036](SPK-0036-recovery-worker-isolation.md) 补 recovery 编译/探针 worker，双轮恢复与 7 项安全验证通过；[0033](SPK-0033-build-entry-audit.md) 为前序入口审查。根外只读运行时、独立研究 helper、总资源与原生解析边界未关闭 |
| 7 | 单一可写语言、隔离输入可恢复、旧 epoch 不回灌 | **满足（内存模型 + 恢复机制）** | 语言协调 60/60；真实网络、多进程、fsync 与解析器未验证 |
| 8 | 六类混用成功/失败夹具与支持矩阵 | **满足（声明子集）** | [0035](SPK-0035-vector-fidelity.md)：混合构建 36/36、双宿主源引擎行内载体/深公式/链接注释矩形/同页精确目标通过；Convert 与 Vector 显式区分。非链接批注、跨页/旋转载体、重复/矢量内嵌套、未知动作明确拒绝；非任意源码与 PDF/UA 支持 |
| 9 | 两宿主引用/页码/链接、反馈有界、失败不发布 | **满足（夹具范围）** | 振荡第 3 轮停止、不发布；[0035](SPK-0035-vector-fidelity.md) 补组件内部 XYZ 目标、宿主↔组件与 HTTP(S)，按源载体变换检查最终目标和点击矩形 |
| 10 | 标准包/混合重建包在声明干净环境构建，不支持组合准确阻断 | **满足（实验包范围）** | 28/28 隔离重建，两宿主缺组件对照通过；混合包依赖 spike driver 与权威快照，非正式文件格式或任意源码编辑后重建能力 |

“满足”均指报告声明的机制/夹具范围，不代表对应产品能力完成。
第 3 条按“不阻塞 UI 帧”判定，**不再把编译完成耗时直接等同于 UI 帧耗时**；
仍需真实窗口证据才能关闭。第 6 条保留原要求，不能因添加运行时挂载就默认满足字面上的项目根限制。
