# Spike 0012：阶段 0 出口条件逐条判定

> **有效性（2026-09-17 登记）**：**本报告是阶段 0 出口条件判定的唯一来源**；其余报告与文档中的状态叙述一律从属于它，与之冲突时以本报告为准。

- 当前结论：**10 条按固定 spike 范围满足，阶段 0 可行性验证收尾，可以进入阶段 1。**
- 更新日期：2026-09-20；依据用户要求核对必要范围，裁决见 [ADR 0023](../adr/ADR-0023-stage0-feasibility-boundary.md)，证据见 [0044](SPK-0044-stage0-scope-review.md)。
- 这包含显式范围调整：安全以固定运行时白名单之外不可访问为准；正式 parser/存储 schema/共享 SDG adapter 和总磁盘配额转入阶段 1 对应前置门禁。不是这些能力已经实现，也不是满足旧字面“根外任何文件都不可读”。
- 既有失败和修复链保留在各报告，不重复作为当前未完成项。0040 的全阶段首轮 40/42、之后分段修复补测与本轮安全 7/7 分开记录，不伪造一次全套通过。

| 9 | 两宿主引用/页码/链接、反馈有界、失败不发布 | **满足（夹具范围）** | 振荡第 3 轮停止、不发布；[0035](SPK-0035-vector-fidelity.md) 补组件内部 XYZ 目标、宿主↔组件与 HTTP(S)，按源载体变换检查最终目标和点击矩形 |
| 10 | 标准包/混合重建包在声明干净环境构建，不支持组合准确阻断 | **满足（实验包范围）** | 28/28 隔离重建，两宿主缺组件对照通过；混合包依赖 spike driver 与权威快照，非正式文件格式或任意源码编辑后重建能力 |

“满足”均指报告声明的机制/夹具范围，不代表对应产品能力完成。
第 3 条按“不阻塞 UI 帧”判定，**不再把编译完成耗时直接等同于 UI 帧耗时**；
真实窗口证据见报告 0030。第 6 条按 ADR 0023 显式修订的运行时白名单边界判定，不声称满足旧字面绝对要求。

## 阶段 1 接手门禁（不继续扩充 P0）

1. 正式 storage 开工前：SQLite/rusqlite → redb 恢复比较，裁决 WAL/快照/内容寻址与持久化 schema；实验会话文件不得转正。
2. 共享 SDG adapter：真实树身份/更新、并发结构冲突、完整动作补偿与恢复；窗口模拟不替代该实现。生产网络放在对应协作阶段。
3. 源码理解扩展前：正式 parser 裁决，保留 Raw、不确定冲突与单一权威。
4. 面向不可信项目交付前：/work 总配额、运行时打包及宿主 decoder/IPC 审查；研究 helper 不作为安全项目入口。
5. 对应平台/能力交付前：跨平台 IME/读屏、完整数学体验、扩大混排支持矩阵；现有通过结论只覆盖报告声明子集。

除已支持路径发生崩溃、数据丢失、隔离失效、错误编辑/渲染或证据无效外，不再新增阶段 0 收尾门槛。
以上后续需求没有删除，也没有被判定为已实现。完整阶段归属与替换路径见 ADR 0023。
