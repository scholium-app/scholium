## 实现与真实缺陷

源码区增加独立滚动视口，草稿操作按钮保持可见，并给源码控件提供方言名称。
egui 0.36.2 TextRun 使用局部坐标与父变换，AccessKit 0.18.1 修复禁用按钮错误的 Enabled/Sensitive。
副本可按发布包哈希逐文件核对，源码差异只有 vendor/README.md 列出的两个文件；许可证门禁通过。

连续输入验收暴露：等待后台排版时原实现删除全部 TextRun，使 AT-SPI Text 接口被注销，
即使新画面已返回，辅助功能查询也可能失败。现在等待期间仍从当前权威文档发布文本与选区，
不发布过期坐标；当前编译结果到达后再恢复字符框。新增回归保护此边界。

统一 Linux 沙箱加入用户 cgroup：整树 2 GiB 内存、禁 swap、64 tasks、OOM 整组终止；
/tmp 使用 256 MiB tmpfs。负对照实际触发多文件 ENOSPC、线程创建 EAGAIN，三个各 768 MiB
子进程被整组 SIGKILL。测试同时读取 cgroup 内核策略，不靠参数字符串推断生效。
旧 Fibonacci 超时夹具会先触发新内存限制；改用有界层数、极大总迭代数的低分配循环，
继续严格要求墙钟退出码 124，未放宽为“任意编译失败”。
