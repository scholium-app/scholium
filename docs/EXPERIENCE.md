# 编辑体验设计

## 1. 体验目标

参考 Liii STEM 的不是视觉外观，而是“环境有焦点、输入有模式、操作有一致语法”的交互模型。
Scholium 在此基础上增加完整源码工作台、格式转换、版本图和协作。

### 工作区组织

Scholium 是科学排版软件，工作区以论文、书籍和技术文档的编辑排版为中心，不能由 P1 的最小样例收窄成笔记界面。
页面编辑模式直接编辑排版内容，默认只有一个编辑面，不常驻重复预览。Source Studio 中源码与排版结果
是同等重要的工作窗格，默认约 1:1 分屏，可调整比例；最终排版检查由用户按需进入，预览与最终输出使用同一引擎。

页面编辑与源码预览都显示真实排版结果，名称区分的是编辑位置：直接在页面上编辑，或通过源码窗格工作（当前源码预览只读）。

顶部自上而下为菜单栏、主工具栏、焦点工具栏和文档标签栏，窗口标题与窗口按钮由操作系统提供。
菜单栏以纯文字列出文件、编辑、插入、格式、文档、视图、工具、帮助，每个命令在菜单里都有完整名称与快捷键；
主工具栏是按功能分组的单色图标，每个图标都有“名称 + 快捷键”悬停提示，未接入的入口灰显并在提示中说明原因；
焦点工具栏随光标所在节点变化，正文中显示文档属性，公式中显示数学操作，并固定放置工作方式切换；
多个文档以标签页切换，标签栏位于工具区下方。窄窗口把放不下的工具按钮收进溢出菜单。
菜单、工具栏、焦点工具栏、命令搜索与快捷键调用同一命令。早期规划的 Ribbon 功能区占高过大、分组空旷，
已改为上述结构，理由与参考图见 [P1 排版工作区规划](plan/P1_UI.md)。
正文优先，导航和诊断等辅助面板按需展开；未接入或当前不可用的命令须明确禁用。
视图切换不改变权威模型。源码来源、草稿、保存状态以及排版后端/revision 必须清楚区分；
状态栏常驻页码、字数、当前上下文、后端标签（排版落后时显示“更新中”）、警告与缩放；具体 revision 可在后端标签的悬停提示或诊断面板中查到。
平台适配、可访问性和真实编辑效率优先于视觉复刻；布局参考、可调整边界与评审检查见
[P1 排版工作区规划](plan/P1_UI.md)。

## 2. 三种模式

### 文本模式

默认模式。直接输入正文；选中后应用粗体/强调/链接等，或先开启样式再输入。方向键可离开行内环境，
`Ctrl/Cmd+Backspace` 解除最内层环境但保留内容。Esc 先取消选区与输入法组合；二者都没有且光标在公式中时，
离开当前公式并把光标放在公式之后。

### 数学模式

`$` 插入行内公式；可配置快捷键插入独立/多行公式。数学输入处理符号间距、槽位和结构导航。
矩阵、分数、根式、上下标、定界符和多行对齐都是显式节点，不靠字符串猜当前槽位。

### 源码模式

进入完整 Source Studio 或 Typst 原生项目当前焦点的 source lens。排版源码语言固定为项目创建/导入时的
LaTeX 或 Typst，Markdown/BibTeX 可作为资源编辑，提供真实语法高亮、补全、诊断、格式化和项目符号。状态栏必须显示当前权威模型和当前源码是否为生成视图。

## 3. 焦点模型

焦点是包含光标的最内层语义节点。breadcrumb 展示从文档到焦点的祖先链，用户可用键盘向父/子/同类
节点移动。选区跨节点时焦点为最小公共祖先，工具栏只显示对整个选区安全的操作。

焦点工具栏由节点 capability 生成：

- 公式：编号、label、显示样式、对齐、源片段。
- 分数/根式/定界符：结构变体和槽位导航。
- 表格/矩阵：行列增删、对齐、边框、合并和继承属性。
- 图片：资源、尺寸、旋转、题注、浮动策略和替代文本。
- 定理/章节：类型、编号、层级、label 和样式角色。
- 引用：key、定位、悬停预览和引用形式。

## 4. 命令输入

按 `\` 打开原位命令面板。解析优先级为当前模式命令、目标方言别名、项目宏、全局命令。候选同时显示
结果预览、参数槽、目标方言输出和快捷键。

回车接受，Tab 补全，Escape 取消。命令插入结构并把光标放入第一个必填槽；Tab 在槽间前进，离开最后
槽后才恢复符号循环语义。命令历史按模式隔离，避免数学候选污染文本输入。

## 5. 高速数学输入

- 乐高符号：短字符序列组合为符号，例如方向、否定、包围和重复；规则可发现且可撤销为一次动作。
- Tab 循环：字符原型在形似、音似或功能等价集合中循环。
- 结构变体：统一快捷键循环分数样式、公式显示方式、矩阵括号、定界符和上下标形态。
- 槽位导航：左右在原子间移动，上下在分子/分母、上下标和矩阵单元格间移动。
- 结构增删：Alt+方向为表格/矩阵/列表增加相邻结构；对应删除键删除行列或结构项。

所有规则由声明式 command/cycle registry 提供，并可在工具提示和命令面板中搜索。

## 6. 结构搜索与替换

搜索既支持文本/正则，也支持结构模式。结构模板允许留空槽作为通配符，例如空分子分母的 frac 匹配
所有分数。结果显示语义预览和对应 LaTeX/Typst 源片段。替换先生成 WorkspacePatch 预览，再原子提交。

## 7. 表格、图片与引用

表格和矩阵从最小结构开始，键盘增删行列；多单元格选区的属性批量应用，新单元格继承相邻上下文。
图片/表格容器与内容分离，容器负责题注、编号、label 和布局。

Bib 文件既可源码编辑，也有文献面板。输入 cite 命令时按 key、作者、标题模糊搜索；引用悬停预览，
点击跳转，重命名 key 生成跨文件语义动作。

## 8. Source Studio

Source Studio 提供：

- LaTeX/Typst 文件树、符号、大纲、跳转、诊断和查找替换。
- 原生结构项目的 Generated、Edited、Out-of-sync、Raw 四种源码状态。
- 修改生成源码后的 compatibility diff：哪些变化映射为语义节点、哪些成为 Raw、哪些无法接受。
- 一键定位当前视觉焦点的源范围，以及从源码跳回视觉节点。
- 同语言多人可同时编辑，项目语言在创建/导入时固定，视图切换不改变语言。
- 状态栏显示项目语言、权威模型、草稿与离线状态；源码错误仍可保存，草稿持久化独立于语义提交。
- 换语言使用「转换为…」生成新项目并展示兼容报告，原项目保留。

源码项目中 Source Studio 是完整权威编辑器。LaTeX 内核首发提供源码编辑、预览、双向定位与诊断；
页面直接编辑 LaTeX 正文另行评估，不能默认套用 Typst 的结构编辑能力。

## 9. 多格式粘贴

普通粘贴优先使用剪贴板的 HTML/MathML 等结构格式，退化到纯文本；“粘贴为”允许显式选择 LaTeX、Typst、
Markdown、HTML、图片或纯文本。检测到源码时先显示目标结构预览与兼容状态，再作为一次 Action 插入。

首发不依赖 AI 的确定性转换；图片 OCR、手写公式和语义恢复后置，并始终展示识别结果供确认。

## 10. 项目引擎预览

Typst 原生项目的页面编辑由 Typst 提供即时排版，不额外常驻一份预览；.typ 源码模式显示 Typst 结果。
LaTeX 项目预览与最终输出使用同一 LaTeX 引擎。LuaLaTeX 实时段落重排以 rtex 为候选（待评估），
全局分页、浮动体、目录与引用由后台整编更新；pdfLaTeX/XeLaTeX 显示“整编预览”与延迟。
状态栏区分引擎、实时/整编来源及是否最新，旧结果不提供当前定位；构建异步且可取消。

另一语言的输出经转换或导出及兼容报告生成，不作为当前项目的预览。

## 11. 协作与文件操作

参与者可处于同一项目的不同视图，同语言多人编辑经 CRDT 合并。Typst 原生项目支持视觉与源码 reconcile 协作；
LaTeX 项目协作编辑权威文本。Raw 显示原文和诊断，同方言保留，跨方言降级或阻止导出。
离线输入显示持久化与同步状态，冲突先预览，不静默覆盖共享正文；权限撤销后保留为本地 fork。

“保存”写当前权威正文与草稿；“另存为”创建同语言副本；「转换为…」建立另一语言的新项目与逐节点兼容报告；
“导出”生成副本并显示依赖、降级及阻断项，不改变当前项目语言。混合组件、跨引擎桥接、混合重建包与团队语言切换
已按 [ADR 0041](adr/ADR-0041-separate-latex-typst-kernels.md) 推迟，详见
[项目语言、跨格式转换与文件操作](MIXED_SOURCE_EDITING.md)。

## 12. 体验验收脚本

- 不碰鼠标输入含分数、根式、矩阵、编号和引用的公式段落。
- 对当前公式切换编号、矩阵括号和分数样式，并逐层解除环境。
- 在视觉视图插入表格后用键盘扩为 4×5，再在源码视图修改一个单元格。
- 在 Typst 原生文档的 source lens 修改受支持语法后回到视觉视图；导出 LaTeX 提供逐节点报告。
- LaTeX 转换夹具中的未知宏同方言保留为 Raw，转换 Typst 时收到降级报告或导出阻断。
- 一名协作者编辑视觉公式，另一名编辑源码，两边收敛且历史可解释。
- 三人同语言源码编辑并重连，IME/待提交草稿可恢复，权限撤销后的离线输入保留为 fork。
- Typst 与 LaTeX 项目各自保存重开并用同一引擎预览和生成 PDF，整编来源与延迟可见。
- 「转换为…」建立另一语言的新项目及兼容报告，原项目保留，不静默覆盖正文。
