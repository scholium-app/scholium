# 实施路线图

路线按产品风险推进。首先验证结构编辑、源码 reconcile、团队单一源码语言和全范围混合构建，随后尽早完成
打开—编辑—保存—重开—双目标输出闭环。团队语言限制不是编译限制，混用范围不能缩减为公式/图像。
产品要求见 [混合源码与团队编辑](MIXED_SOURCE_EDITING.md)，实现方案仍待验证。

## 阶段 0：七项否决性验证（工期由验证范围重估）

### 交付

1. 原生结构/源码编辑 spike：严格按 Iced → GPUI → C++ EUI-NEO → Slint 或 egui 依次验证；
   每个候选运行同一组嵌套文本、数学结构、TreeSelection、中文 IME、源码编辑和无障碍脚本。
   具体任务、进入下一候选的条件与报告见 [原生 UI 验证计划](NATIVE_UI_VALIDATION.md)；
   进度见[报告 0001](spikes/0001-native-ui-iced.md)：**Iced 结论 Fail**（无 accesskit）；
   [报告 0002](spikes/0002-native-ui-gpui.md)：**GPUI 结论 Fail**（同样无无障碍，且核心没有文本输入控件）；
   [报告 0003](spikes/0003-native-ui-prescreen.md)：EUI-NEO 无无障碍不投入、Slint 被许可证政策阻断；
   [报告 0004](spikes/0004-native-ui-egui.md)：**egui 结论 Blocked（首个无硬性 Fail）**——可访问性与
   输入法均实测可用，是目前唯一同时具备两者的候选；结构编辑交互、性能与预览定位未验收。
   无障碍测试必须先启用会话开关（`org.a11y.Status IsEnabled`），否则是假阴性；
   输入法的自动注入在共享会话里不稳定，只能作参考，不能据一次运行否定框架。
   **第 1 项判定：egui 通过共同验收的可验证部分**（唯一同时具备中文输入法与可访问性的候选），
   锁定 eframe/egui 0.36.2 + winit 0.30.13 + accesskit 0.24.1，平台 Arch Linux / niri 26.04 / fcitx5 5.1.22；
   未承诺：鼠标拖拽选区、完整结构编辑界面、正式渲染质量、增量布局。
2. Typst 映射 spike：20 页 SDG 生成 Typst、增量编译、NodeId ↔ glyph/preview 双向定位。
   进度见[报告 0005](spikes/0005-typst-mapping.md)：**结论 Pass（机制）**——20 页编译 637 ms，
   NodeId ↔ 预览位置 257/257 双向解析；改一处后增量编译 183 ms（冷的 29%）。
   由此确定：预览必须异步去抖、按百毫秒级定 p95，不能按 16 ms 帧预算设计。
   行内结构坐标已补齐（分数/上下标有区间、反查 40/40），已渲染首页叠加锚点核对通过；
   多页覆盖已验证（20 页每页有锚点、跨页抽样反查 40/40），文本字符级映射已验证
   （8 字一块插值误差平均 0.24 pt，反查 36/38 完全一致）。尚未覆盖：跨页结构与跨行文本块。
   出口条件第 3 条实测：单字符路径 p95 21 ms、最坏（改首段）208 ms，**不满足 16 ms 的字面要求**，
   只能靠异步编译加丢弃过期结果来满足『不阻塞帧』的意图；旧 revision 不闪回已用结果门验证（含负对照）。
3. 源码 reconcile spike：同一小文档生成 LaTeX/Typst，手改受支持结构后可靠映射回 SDG；未知语法变 Raw。
   进度见[报告 0006](spikes/0006-source-reconcile.md)：**结论 Pass（限定范围）**——两种方言 8/8 用例通过，
   Raw 原文逐字保留且往返一致；结构级重构（增删行、重排、文本中间新建结构）一律报冲突，未支持。
4. CRDT 赛马：共享树和共享文本的两人离线编辑、本地 undo、快照与 10 万次动作。
5. 构建/恢复 spike：两种引擎隔离构建、WAL 与未提交草稿恢复、外部源码修改冲突。
6. 团队语言协调 spike：同语言多人编辑，切换屏障、epoch 隔离、服务重启、网络分区、旧包和恶意写集验证。
   进度见[报告 0009](spikes/0009-team-language.md)：**结论 Pass（内存模型 + 确定性时序）**——60 个用例
   60/60 通过，每条判据都有成功夹具与失败夹具；真实网络、多进程、磁盘 fsync 与解析器均未验证，
   写集校验只是字符串抽检、不足以宣称能阻止恶意客户端。
7. 混合构建 spike：正文/跨页表格、公式/图表、自定义宏、模板作用域、双向引用/最终页码/链接；
   分别以 LaTeX 和 Typst 为宿主输出，验证标准源码包与混合重建包。不能只做截图嵌入。

### 出口条件

- 中文 IME、嵌套数学光标、结构选区和源码工作台在原生候选中通过共同验收；记录锁定版本及真实平台。
- 构建与运行不依赖 npm/Node.js/WebView；C/C++/Zig 依赖有明确 ABI、生命周期和构建记录，且许可证落入
  `AGENT.md` 许可证政策的允许清单，`cargo deny` 通过。
- Typst 快速预览单字符路径 p95 不阻塞 16ms 帧，旧 revision 不闪回。
- 受支持 LaTeX/Typst source edit 可 round-trip，Raw 不丢失。
- 两端收敛且本地撤销保留远端输入。
- 不可信 LaTeX/Typst 无法执行外部命令或读取项目根外文件。
- 同一共享分支无两种源码语言同时可写窗口；离线及被隔离输入可恢复，旧 epoch 不自动回灌。
- 六类混用内容各有可复现成功夹具及失败夹具；明确支持的模板/工具链/桥接矩阵。
- 两种宿主的最终引用、页码、链接有效；引用反馈有轮数上限，失败阻止正式输出。
- 标准目标包与混合重建包在声明的干净环境可构建，无法支持的组合被准确阻断。

任何一项失败都先改架构，不得用空 crate 宣称阶段完成。每项产出 ADR、可复现命令和失败数据。

## 阶段 1：最小编辑、保存与格式交换闭环

实现 model、document、collab engine adapter、storage WAL 和 app 最小壳。支持段落、heading、粗体/强调、
行内/独立数学、分数、根式、上下标、定界符；实现 TreeCursor、selection、focus、undo 和 Typst 快速预览。

出口：用户不打开源码即可完成一页含中英文和公式的笔记；点击预览定位、光标、IME、保存、强杀恢复
全部通过；所有共享正文写入均产生 Action，未提交源码草稿也有独立持久化记录。
同时提供最小 Source Studio：`.tex/.typ` 打开、同格式保存、语法错误保存、外部冲突、单机语言控制及
受支持子集的两种源码/PDF 输出。暂不要求完整模板混用覆盖；这一阶段不能宣称全范围混用已交付。

## 阶段 2：Liii 式高效输入与文档结构

实现文本/数学/命令模式、焦点工具栏、`\` 命令补全、Tab 槽位与符号循环、乐高符号、结构变体、
结构导航/搜索；加入列表、定理、证明、矩阵、多行公式、表格、图片、题注、label/ref/cite、脚注和代码块。

出口：完成 `EXPERIENCE.md` 中结构输入与导航的验收脚本；源码混用和团队脚本归后续阶段。
不用源码写出含定理、矩阵、图表、交叉引用和文献的短论文；每个工具栏操作都可撤销且有两种目标能力状态。

## 阶段 3：完整 Source Studio、混合项目与双目标输出

完善 format、latex、typst、markdown、bib adapters 和 Source Studio；实现 source lens、reconcile、持久草稿、
Raw/ForeignSource、宏/模板作用域、跨组件引用与有界多轮构建。完成混合项目保存重开、双格式另存为、
标准目标包/混合重建包以及两种后端的最终 PDF，不把核心格式交换推迟到产品化阶段。

出口：

- 原生项目可在 LaTeX/Typst source lens 修改支持子集并回到视觉视图。
- 现有 `.tex/.typ` 项目可原地源码编辑；可逆区域能在视觉视图修改且未触及字节不变。
- LaTeX ↔ Typst 转换逐节点报告 Exact/Equivalent/Raw/Degraded/Dropped。
- 选择 LaTeX 发布时快速预览与最终预览后端标识清楚，不冒充一致；两种引擎可按依赖并行。
- 正文、跨页表格、宏、模板、双向引用分别有通过两种宿主的真实项目；保存重开保住原文/依赖/草稿。
- 另存为创建独立目标项目，导出不改变编辑语言；同一快照的两种目标报告编辑性、依赖和保真度。
- 缺组件、模板冲突、引用不收敛阻止正式输出；标准包与混合包按声明在干净环境验证。
- 未覆盖的语言/模板组合有兼容矩阵和错误，不以 Raw 原文保留宣称支持。

## 阶段 4：非线性历史

实现 actor scoped undo/redo、时间线、checkpoint、branch、任意 revert、cherry-pick、merge session、
结构 diff 与语义冲突检测。视觉动作和源码动作在同一时间线展示。

出口：远端动作穿插模拟下只撤本人操作；从历史分叉、视觉/源码分别修改、合并后可重启复现同一结果；
无法可靠 revert 的动作明确标记 non-revertible。语言 epoch 不随 undo/merge 回退；涉及源码的历史操作重新
取得当前语言许可，两种语言的组合变更按可恢复步骤处理。

## 阶段 5：团队协作与语言切换产品化

实现 sync-server、鉴权、角色、邀请、共享树/文本 update、快照、presence、断线队列和撤权后的本地 fork。
实现阶段 0 已验证的语言协调、写集校验、持久控制记录、许可、drain/隔离及草稿恢复交互。
协作者可同时查看视觉与两种源码视图，但同一共享项目分支只能有一种源码语言可写。

出口：三端在线/离线交替编辑最终收敛；视觉与源码协作产生 Raw 时双方收到诊断；服务器重启、重复/乱序
消息不丢不重；viewer 无法写。两位同语言源码编辑者和视觉编辑者可协作；竞争切换、掉线、旧 epoch、
外部修改、混合语义写集、服务重启都无法绕过语言限制。离线源码进入草稿/fork，重连合入流程不丢输入。

## 阶段 6：扩展导出与产品化

在阶段 3 的源码项目/PDF 输出基础上完成 HTML、Markdown、纯文本导出与 Copy As；门控 DOCX/EPUB；补齐冲突 UI、恢复
中心、无障碍、i18n、更新、三平台打包、诊断包、性能和安全审计。

出口：默认策略不存在静默 Dropped；三平台发布候选通过完整门禁；升级/回滚不损坏语义正文、源码、
历史或凭据。

## 依赖关系

```text
否决性验证
  └─ 最小编辑、保存与格式交换闭环
       └─ 高效输入与文档结构
            ├─ Source Studio 与混合输出 ── 扩展导出与产品化
            └─ 非线性历史 ─────────── 团队协作与语言切换
```

团队协作还依赖 Source Studio 与混合输出的源码写集/草稿/组件合约；最终产品化依赖两条路径全部验收。

旧的 28–37 周总估算不再适用。团队语言协调与完整范围混用增加了关键路径；阶段 0 后根据团队配置、
模板/桥接矩阵和性能数据分别估算各阶段，当前不承诺新日期。阶段 1 交付最小可保存/交换版本，阶段 3
交付完整混合项目与双目标输出，阶段 5 交付团队协作。AI、CAS、独立绘图工具和插件执行仍在范围外；
已有 LaTeX/Typst 绘图代码作为混合内容受支持，与新增绘图工具不是同一要求。

## 每阶段完成定义

- 用户验收脚本通过，而非只有单元测试或 trait。
- 设计文档和 ADR 与实现一致。
- 公共 API、错误语义、数据版本和迁移测试完整。
- 单元、属性、集成和需要的端到端测试通过。
- 性能、安全、隐私和无障碍影响已记录。
- 用户可观察的失败有诊断与恢复路径。
- 没有用 TODO、假数据、空实现或固定示例冒充出口能力。
