# Typst 编辑内核接入主程序计划

## 1. 交付目标

在 `scholium-app` 的所见即所得编辑面输入时，由同一 Typst 布局产物提供正文/公式、
光标、命中、选区与 IME 锚点；移除已提交内容的 egui 临时回显和随后替换页面的交接。
保留单一编辑面、Ribbon、保存恢复和源码工作区，不以独立演示窗口替代主程序验收。

本页定义将来的接入顺序和验收，不表示功能已经交付。内核方向与 K1–K4 判据见
[内核计划](TYPST_EDIT_KERNEL.md)、[ADR 0032](../adr/ADR-0032-typst-edit-kernel.md)；
限定实验及失败项见[报告 0051](../spikes/SPK-0051-typst-caret-native-editor.md)、
[报告 0052](../spikes/SPK-0052-typst-incremental-content.md)。阶段判定仍只以
[报告 0012](../spikes/SPK-0012-exit-criteria.md)为准。

区分三个交付出口：

1. **主程序候选可操作**：从 `scholium-app` 启动，显式选择开发验证入口，在隔离会话文件中
   编辑限定结构；该入口的页面不走回显。报告给出准确命令、构建提交、实际后端和支持范围。
2. **主程序候选兼容通过**：旧文档迁移、选区/撤销、保存恢复、分页及实际显示性能通过。
3. **默认路径替换完成**：依赖安全与全部替换门禁通过，普通启动默认使用新内核；随后清理
   旧回显代码及其测试。第一项不能表述为第三项，默认程序行为须在每批报告中单独说明。

## 2. 接入点与职责

以下文件是代码定位入口，公共类型与存储格式的具体变更须先写迁移 ADR，并同步模块合约。

| 接入点 | 将承担的变更 |
|---|---|
| `crates/scholium-model/src/lib.rs` | 稳定 inline/文本叶/数学节点身份；版本化结构和语义端点，Typst 类型不进入模型 |
| `crates/scholium-document/src/lib.rs` | LocalSession 接受文字/结构命令，发布已接受变更；拆块/合块/格式操作维持身份和动作边界 |
| `crates/scholium-storage/src/lib.rs` | schema 识别、旧会话无损迁移和失败保护；保存结构空槽、身份及请求日志 |
| `crates/scholium-typst/src/` | model → Content 增量 adapter、常驻编辑布局会话、同源 Scene；保留源码/严格编译用途 |
| `crates/scholium-app/src/session.rs` | 串行接受输入、派发布局更新、管理会话代际、采纳场景；保存始终读取权威会话 |
| `crates/scholium-app/src/page_editor/` | 语义位置 ↔ 当前 Scene 几何；绘制、命中、选区与 IME 共用 placement，取消新路径回显 |
| `crates/scholium-app/src/main.rs` | 输入/会话/绘制的帧时序与开发入口；验证布局任务不阻塞 UI |

不把 `spikes/native-ui/core` 的 Editor 嵌入主程序充当另一份可写正文；复用实验结论与可抽取的
布局算法适配代码。权威仍由 document/session 管理，UI 与 Typst 会话只持有派生物。
不预建空 session/render crate，先沿既有职责接入；确需抽取时另行裁决依赖方向。

## 3. 必须先固定的合约

### 稳定身份与迁移

文本与数学原子、Row、Fraction 及其槽位拥有稳定 typed ID。编号与源码 offset 不充当身份，
Typst opaque origin 只由 adapter 注册和反查。slot 名称、叶内 UTF-8 byte、affinity、字素导航
和页面 pt 坐标分别定义；界面缩放/滚动统一应用 Scene placement。

首批覆盖正文、粗体/强调、一二级标题、数学文字/符号、Row、Fraction、必填 Hole。
根式、上下标、定界符、矩阵等须逐项扩展和验收，不能把分数支持称为完整数学编辑。
字符串公式导入按确定语法和 capability 报告转换；未知或不能证明等价的旧公式作为 RawMath
保留原串、方言与诊断，不猜测可写槽位，也不静默变成正文。任意用户代码继续走沙箱边界。

升级 schema 前保存可恢复副本。旧文档、已有快照和请求日志分别定义兼容策略；迁移后节点
身份保存重开不变，未转换内容逐字保留。新格式不得让旧写入器误读后覆盖；使用隔离目标文件
和格式版本门禁，校验完成后才切换。迁移失败保留原文件，恢复失败继续阻止保存覆盖。

结构空槽属于可保存语义；提示框/preedit 是显示状态，不写正文。Strict 输出拒绝必填 Hole。
原串若只作导入来源记录，不允许与数学树同时可写；RawMath 的原串则是该节点的唯一内容。

### 输入接受与渲染代际

规划场景身份至少区分文档、会话代际、布局请求、语义 revision、profile 和资源 generation，
各字段使用 typed ID。revision 相同不能单独证明两个结果对应同一内容。
新建、恢复、撤销/重做跳转、迁移及布局 worker 重建启动新会话代际，并清理旧场景引用。
渲染代际不伪装成用户动作，不改变现有存储的请求日志与语义 revision 对应关系。

每个输入意图先由 session 串行接受，才生成 Content delta。待处理输入保留明确状态；
拒绝内容可复制但不画成已提交正文。容量受控、顺序与背压明确，多事件帧、粘贴和连续输入
不能覆盖单个 pending 槽而丢字符；仅已接受且连续的节点更新可以合并，动作边界仍由核心管理。
原生结构输入不再经过全文 markup 的重解析；生成源码保留为只读投影/源码工作区用途。

增量包检查 base；Scene 检查文档/代际/请求/profile/资源及完整资源引用。丢中间显示结果
不丢其结构修改或仍被后继引用的资源。base 错误请求完整重同步，不在 UI 猜补缺失节点。

### 当前画面、几何与失败

Frame、placements、文字 cluster、装饰、caret/selection 几何和绘制资源一起验证、采纳。
未变片段只有在节点版本与依赖验证后才能纳入新 Scene；旧结果不能按新源码解释位置。
未完成区域标记 pending，禁止过期点击与旧 caret；若区域坐标的当前有效性无法证明，
禁用其交互。已提交正文和结构公式只由 Typst 绘制；IME preedit 可以单独显示。

布局失败保留权威编辑和诊断，不在同一编辑面悄悄切回 egui 文字回显。Raw/derived 内容按
capability 提供节点选择或显式源码入口，不猜文本端点。源码项目和最终预览仍按各自边界运行。

## 4. 分批实施

### A：身份、会话与旧文件迁移

先形成迁移 ADR 和纯核心兼容夹具，再在同一个 LocalSession 内实现首批稳定结构及操作。
允许为过渡版本保留旧读取入口，但不能靠持续双写原串/数学树维持两个权威内容。
移植结构命令与叶/槽位位置，适配现有粗体、标题、拆块/合块和请求重复检测。
保留单机撤销/重做的既有语义；由新代际隔离 revision 跳转，单机栈不冒充协作历史。

验收：旧正文/样式/公式不丢失；未知公式无损保留；IDs 经编辑、拆合及保存重开仍符合规则；
分数创建/填槽/撤销为原子动作；坏 schema/引用/Unicode 端点不部分应用；迁移失败不覆盖原库。
交付物是迁移报告与可用于主程序的会话适配，默认界面是否改变须明确记录。

### B：主程序内的首个候选闭环

先验证锁定 fork 的来源、重建与同版本 crate 组，统一 Cargo patch，避免混用 registry/fork
类型；不让正式代码依赖 spike 可执行文件或被忽略的临时目录。独立 stock reference 保留。
依赖审计纳入此批的开发报告；通告未处理前不合入默认发行依赖，不增加 ignore 绕过门禁。

在 `scholium-app` 增加显式开发候选入口，复用其 LocalSession、SessionBridge、Ribbon 和
SessionStore；测试使用既有 `SCHOLIUM_SESSION_FILE` 指向隔离新库。具体启动选项在实现时
固定并写入报告，此页不把尚未提供的命令说成可运行。

将持久 Content adapter/worker 接入该入口，取消结构编辑等待的全文源码生成和编译去抖；
提交语义更新后异步获得同源 Scene。输入在绘制前接受/发送，worker 完成唤醒 UI，UI 不等待
join 或运行 Typst。先可使用完整 Scene 和受控不分页布局，明确标记候选能力，分页在 D 批补齐。

验收使用**主程序**：新建，输入中英文/空格，插入分数并填写空分母，嵌套，撤销/重做，
保存退出重开，继续编辑；界面显示所用后端。录制输入前后过程并核对绘制调用，只有 IME
preedit 等临时交互层可画文字，已提交正文/公式不产生 egui 回显。该批必须交付主程序命令和
可重复操作证据，不能再次只交付 `typst-edit-window` 截图。

### C：日常编辑与版本竞态

把 page_editor 的文字与数学叶/槽位命中、方向键/Tab、拖选、跨 inline/块替换、复制剪切粘贴、
换行拆合、格式操作、撤销/重做、滚动/翻页跟随和 Ribbon 命令接到同一结构会话。
Scene 几何承担光标、选区和 IME 候选位置，淘汰新路径的 joined-markup 几何位移桥。

故障夹具覆盖 worker 慢、队列满、base 错误、结果乱序、快速切文档/视图、撤销后相同 revision
重新编辑、字号/宽度/缩放改变及恢复失败；单独验证被拒绝输入、未接受输入和已接受输入。
合字不精确 caret、bidi、derived 与未知节点能力显式记录。实机输入法和无障碍接口单独验收。

验收：现有已承诺编辑场景有逐项迁移结果；动作不丢、目标不漂移、选区替换一次提交；
拒绝/旧 Scene 不成为 current；撤销后的旧 worker 结果即便 revision 相同也不能采纳。

### D：Typst flow 分页、增量场景与显示性能

把实验的段落复用扩展到拥有其数据的 flow 准备结果和分页检查点，从最早受影响点重放，
直到输出及后续入口状态都一致。不能在 app 独立冷编译各段并拼接成伪分页。
页面/片段资源与几何同时增量替换，work budget、取消点和队列/缓存内存有界；优先活跃位置
的布局仍须依赖有效检查点，不跳过未验证的上文上下文。

分别验证 1/64/256 段首中尾，跨页增删和段落延续、宽度/字体族/字号/资源变化；脚注、
计数/query/show/context 等跨范围依赖单列。未知依赖保守完整重排，不承诺任意程序逐键局部求值。
编辑结果与完整 Typst 支持子集对照，不以“高度相同”判断页面可复用。

定位接受、排队、Content、布局/几何、分页、栅格化、纹理提交、UI 采纳和实际呈现各阶段。
核实抓屏成本和实际刷新率，虚拟 framebuffer 观测不能替代物理 60 Hz 呈现证明。
门槛沿用 K3/K4：暖态活跃段落布局/几何 p95 ≤ 8 ms；受控 60 Hz 主程序窗口接受到当前
可操作画面 p95 ≤ 32 ms，10 Hz 输入至少 30 秒。冷字体、超长单段、复杂公式另报。

### E：默认替换与旧路径清理

汇总 A–D 和 K1–K4 的逐项证据，覆盖保存/崩溃恢复、结构数学、样式/版式、选区、输入法、
无障碍、源码投影/严格输出与现有支持范围。依赖漏洞需经兼容升级或真实维护替代处理，
版面/字体/资源解析重新对照；安全/许可证/来源/完整 CI 不通过则不默认发行。

通过后普通启动使用新编辑内核，确认没有依赖开发选项才生效；移除 `echo_blocks`、
pending 正文回显状态和新编辑路径的 markup 坐标桥，重写对应的“必须回显”测试为同源场景测试。
独立源码预览/最终编译继续保留。切后端若仍保留回退入口，须显式重建布局会话，不能输入中
自动切换；旧格式不能因回退被新代码覆盖。最终报告记录正常启动命令与实际二进制/提交。

## 5. PR 与证据边界

按 A–E 的职责分批；A 的 schema/兼容策略必须能独立审阅。B 的开发入口、C 的交互适配、
D 的分页/性能、E 的默认切换不压成一个难以回退的大提交。按依赖顺序验证、合并，提交带 DCO。
候选依赖门禁未通过时保留开发分支与证据，不把失败静默转成 CI 例外。

每批报告放 `docs/spikes/`，回链路线图对应项；报告同时写明独立探针、主程序候选和普通启动
各自行为，列出失败项、源码/补丁/字体/资源版本及复现命令。本计划和规范不记录完成勾选或进度。
首个实现任务为 A 的稳定身份、渲染代际与旧会话迁移裁决/夹具；紧接 B 的主程序候选闭环。
