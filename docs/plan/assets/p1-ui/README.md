无需访问原会话即可查看。为控制仓库体积，入库前已去除元数据并量化为 256 色。

图中文稿、作者与文档属性是示例内容；纸面由设计工具示意绘制，实际纸面以 Typst 排版为准。
图标为 Lucide 风格线性图标；图片不包含字体文件或第三方应用实现。
这些是布局与视觉参考，不是原生应用运行证据，不证明源码编译、排版一致或编辑功能可用；
已知需要在实施时修正的设计稿问题与已确认决策见 [P1_UI.md](../../P1_UI.md)。

维护时先更新体验规范与布局规划中受影响的内容，再替换对应图片；同一组图使用同一文稿与相近窗口尺寸。
只有主要空间关系或令牌改变时才需要刷新图片；日常字体回退、图标与平台适配无需逐次重画。
真实界面验收截图放入对应的开发日志，不能用这里的设计稿替代。
