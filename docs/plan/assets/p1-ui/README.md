# P1 工作区参考图

这两张 PNG 来自用户认可的 Scholium 工作区草图。
它们随仓库文档保存，无需启动服务、安装浏览器或访问原会话即可查看。

| 文件 | 内容 |
|---|---|
| `wysiwyg.png` | 标准菜单、紧凑工具栏与单一所见即所得编辑面 |
| `source-preview.png` | 同一原生文档的 LaTeX 生成源码与约等宽 Typst 快速预览 |

图中文字和文稿是示例内容，界面由本项目设计草图绘制；不是 Liii STEM 或其他软件的截图。
图标来自会话草图运行环境提供的 Lucide 图标集；图片不包含字体文件或第三方应用实现。
这些是布局参考，不是原生应用运行证据，不证明源码编译、文稿排版一致或编辑功能可用。
图片呈现当前视口，上下文中没有显示的区域以 [P1_UI.md](../../P1_UI.md) 的文字规划为准。
截图的深色主题、字体、像素尺寸、可见行数和视口裁切不是实施约束。

维护时先更新体验规范与布局规划中受影响的内容，再替换对应图片；两图使用同一文稿、同一主题和相近窗口宽度，
源码模式恢复等宽并收起辅助面板。避免依赖个人绝对路径或临时预览地址。
只有主要空间关系改变时才需要刷新图片；日常字体、图标、尺寸和原生平台适配无需逐次重拍。
后续真实界面验收图应放入相应验证记录，不能用这里的草图替代。
