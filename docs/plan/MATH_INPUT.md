# 数学输入计划

> 计划文档（将来时）：定义要做什么、什么算通过，不记录进度。依据 [ADR 0048](../adr/ADR-0048-shared-math-input-keymap.md)；
> 能力参照 [Liii STEM 数学模式指南](https://liiistem.cn/docs/guide-equation)、[数学编辑快速入门](https://liiistem.cn/docs/tutorial/tuto-math-edit)、
> [高效编辑指南](https://liiistem.cn/docs/guide-tab)，调研见 [Liii STEM 体验调研](../research/LIIISTEM_EXPERIENCE.md)。

## 目标

两种项目语言共用一套达到 Liii STEM 水平的数学编辑：同样的按键序列在 Typst 项目和 LaTeX 项目里得到等价公式。
只借鉴交互设计，不复制 Liii/Mogan 的实现、数据文件、图标或文案。

## 结构

```text
数学输入引擎（共享底座，无 UI、无 Typst/LaTeX 依赖）
├── data       符号表 / 组合规则 / Tab 循环 / 结构模板与变体 / \ 命令名（声明式文件，测试校验）
├── engine     键入事件 + 数学上下文 → 抽象数学编辑；Tab 三种作用的判定；`\` 行内命令的候选与接受
└── accept     共享验收脚本：按键序列 → 期望的抽象公式树
Typst 适配器   抽象数学编辑 → StructuralEdit（结构文档）
LaTeX 适配器   抽象数学编辑 → 已确认数学范围内的最小 .tex 补丁（L3，依赖 rtex 公式源码归属）
键位表         默认键位文件 + 用户覆盖 → 命令注册表（作用域、冲突检查、帮助与工具提示生成）
```

引擎不持有文档：内核把“当前槽位、光标前的原子、所在结构”交给引擎，引擎返回编辑意图，由内核按自己的权威模型执行并负责撤销。

## 键位表

- 默认键位文件随应用发布，按命令 id 绑定；`CommandSpec` 不再含快捷键字面量。
- 组合键：Ctrl / Alt / Shift / Meta；macOS 上 Cmd 对应其他平台的 Ctrl，Option 对应 Alt。
- 作用域：全局、页面正文、公式、源码编辑器、焦点结构类型（分数、矩阵、列表……）。同作用域冲突与未知命令 id 由测试拒绝。
- 用户覆盖文件位于用户配置目录，逐条覆盖或解除默认绑定；解析失败时保留默认表并给出诊断，不让应用失去全部快捷键。
- 帮助 → 快捷键、菜单项右侧的提示、工具栏悬停提示都从生效的键位表生成。
- 默认绑定以 Liii/Mogan 习惯为基线（ADR 0048 第 3 条）。与窗口管理器冲突的组合（例如被 niri 占用的 Alt 组合）在默认表里换键并注明原因。
- 改键界面不在本计划首批，放在产品化阶段；首批只要求文件可改、改后生效。

## 能力对照与归属阶段

阶段指[路线图](ROADMAP.md)阶段。“共享”指进数学输入引擎或键位表，两个内核都用。

| Liii 能力 | 本项目做法 | 阶段 |
|---|---|---|
| 行内 `$`、独立公式、多行 align/eqnarray、aligned | 行内与独立已有结构；多行对齐为新结构，回车换行、关系符自动对齐 | 行内/独立：1；多行：2 |
| 组合符号（`<=` ⩽、`->` →、`@@` ∞、`RR` ℝ、否定 `/`） | 共享组合规则表 | 1（核心表）；2（全集） |
| Tab / Shift+Tab 符号循环（希腊字母、关系、箭头、集合、黑板体/花体/哥特体） | 共享循环表；Tab 按上下文在命令补全、候选循环、槽位前进三种作用间判定，焦点栏提示（ADR 0048 第 3 条） | 1 |
| 页面中键入 `\` 输入 LaTeX 命令（行内命令框 + 补全列表，如 `\ve` → vect、vee…） | 共享命令名表；正文与公式中都可用；回车/Tab 接受，Esc 取消 | 1（框架与已有符号、结构）；2（全集与项目宏） |
| 括号自动配对、`\|x\|`、`‖x‖`、`⌊x⌋`、`⌈x⌉`，退格使右括号隐形 | 键入即生成可伸缩定界符（ADR 0046 节点） | 1 |
| 键位：分数、根式、独立公式、矩阵、上置/下置 | 键位表，Alt 系组合 | 1（已有结构迁移）；2（新结构） |
| 方向键在原子/槽位间移动，Alt+←/→ 结构遍历 | 方向键与 Tab（无候选时）都能前进槽位；结构遍历为新命令 | 1（方向键与 Tab）；2（Alt 遍历） |
| 结构变体 Alt+Shift+↑/↓（行内↔独立、分数样式、矩阵括号、括号种类、上标↔下标） | 共享变体表 | 2 |
| 拆除最内层结构 Ctrl+Backspace | 引擎意图“拆除”，两内核各自执行 | 2 |
| 上下标、撇号与撇号变体 | 上下标已有；撇号为符号 | 1（撇号） |
| 重音与宽重音（向量、帽子、波浪、横线、点）、上下大括号 | 新结构 | 2 |
| 上置/下置标注、可伸缩箭头加标注 | 新结构 | 2 |
| 大运算符（∫∬∭∮∑∏⋃⋂）与上下限，独立公式中上下限在上下方 | 符号 + 上下限结构 | 2 |
| 矩阵 4 种括号、行列式、分情况、二项式；Alt+→/↓ 加列加行、Alt+Backspace/Delete 删 | 新结构 + 行列命令 | 2 |
| 公式编号、label、eqref、悬停预览、公式与引用间跳转 | 与文档引用系统共用 | 2 |
| 数学字体（黑板体、花体、哥特体、粗体）、省略号 | 符号表 + 循环 | 2 |
| 算子名（sin、log、lim、max……）直立与间距 | 写论文影响排版，随结构实现（ADR 0048 第 4 条） | 2 |
| 直立常数 e、i、d | 符号表提供直立变体 | 2 |
| 同类结构跳转 Ctrl+PgUp/PgDn | 结构导航 | 2 |
| 带空槽通配的结构搜索与替换 | 见 [EXPERIENCE §6](../EXPERIENCE.md#6-结构搜索与替换) | 2 |
| 隐形乘号/分隔符、合法性着色、优先级高亮、复制到 Python/CAS | 不影响排版，暂不做（ADR 0048 第 4 条） | 不在范围 |
| LaTeX 项目中在页面上编辑公式 | LaTeX 适配器接入同一引擎 | 3（L3） |

## 分批

1. **阶段 1，键位与引擎骨架**：键位表与 Alt 支持；把现有结构（分数、根式、定界符、上下标、独立公式）的输入迁移到引擎；
   核心组合符号与 Tab 三种作用（补全、候选循环、槽位前进）及焦点栏提示；`\` 行内命令框与补全（覆盖已有符号与结构）；括号自动配对。
2. **阶段 2a，输入能力**：结构变体、拆除、`\` 命令全集与项目宏、Alt 结构遍历、同类跳转、组合与循环全集。
3. **阶段 2b，数学结构全集**：上表阶段 2 的结构，每个都满足 ADR 0045 的停点与删除规则、两种字体下与原版 Typst 像素一致。
4. **阶段 3，LaTeX 适配器**：L3 ADR 确定范围后，LaTeX 项目的页面内公式编辑接入同一引擎。

## 待验证

- 公式内中文输入法：fcitx5 处于中文状态时会截走组合符号与 Tab 所需的原始按键。候选方案是公式内默认关闭输入法组合，
  文本槽内恢复。在真实 fcitx5/niri 环境实测后裁决，结论写入本计划。
- Alt 系组合在 niri、GNOME、KDE、Windows、macOS 上的占用情况，决定默认表需要哪些替代键。

## 验收

- 数据表测试：每个符号有 LaTeX 名与 Typst 名或显式“不支持”标记；组合规则无前缀冲突；循环表闭合且可反向。
- 共享验收脚本：一组按 Liii 指南整理的按键序列（例如 `a _ n → ^ 2`、`R R Tab`、`< =`、`| x`）在引擎层得到期望的抽象公式树；
  阶段 1–2 由 Typst 内核实际执行并比对，阶段 3 由 LaTeX 内核再跑一遍并与命令行构建结果比对。
- 键位：默认表无冲突；用户覆盖生效；帮助列表与菜单提示与生效表一致；改键不需要重新编译。
- Tab：每种上下文下按 Tab 的结果与焦点栏提示一致，有逐条测试。
- 真实窗口检查覆盖组合符号、Tab 三种作用、`\` 行内命令、括号自动配对、结构键与变体；输入法实测记录在开发日志。
