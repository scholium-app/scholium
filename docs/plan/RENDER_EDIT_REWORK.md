# 渲染与编辑改进计划

本页规划[阶段 1](ROADMAP.md#阶段-1最小编辑保存与格式交换闭环)内预览渲染质量与页面编辑体验的
改进顺序、验收判据与边界。它回答两个用户报告的问题：**字体渲染模糊**与**编辑不跟手**。
证据基础是[报告 0045](../spikes/SPK-0045-render-latency-baseline.md)（延迟链分解）与
2026-09-25 的代码评审；后者记录在[开发日志](../log/render-edit-review.md)。
本页只定义要做什么与什么算通过，不声称任何条目已实现。

## 问题陈述（按证据）

1. **模糊**：页面以固定 2 px/pt 光栅化（`scholium-typst` 的 `PIXELS_PER_PT`），再按任意
   逻辑比例显示。100% 缩放下显示比例 ≈1.33 逻辑 px/pt，在 1x 显示器上位图缩到 0.67 倍、
   2x 显示器上拉到 1.33 倍，配合线性过滤，常见缩放档位均不清晰。
2. **不跟手**：击键后字形要等"去抖 20ms → 全文档重编译 → 采纳 → 整页光栅 → 采纳"两跳流水线。
   报告 0045：release 下 64 段 p95 23ms、256 段 p95 189ms；debug 下分别 153ms / 1417ms。
   **大头是全文档重编译，光栅仅 2–7ms（release）**。期间击键字符不可见（无乐观渲染），
   连续击键重置去抖使结果反复作废。
3. **死区**：编译未返回期间几何为空——点击失效、Home/End 跳文档首尾、光标冻结或落在
   硬编码页边距坐标。
4. **坐标模型**：页面编辑器光标是全文档拼接字符串的字节偏移，每帧全量重建；
   `focus_after_*` 三个启发式字段补偿异步回声。该模型是死区与难用的共同根源。
5. **字体策略**：正文依赖系统存在 Times New Roman / SimSun，缺失时静默回退到 typst-kit
   内嵌字体（无 CJK 衬线），无诊断提示。
6. **状态栏口径**：自报耗时只含编译段，不含光栅与调度，低估体感延迟。

## 与既有规范的关系

- [体验规范](../EXPERIENCE.md)与[P1 规划](P1_UI.md)的"单一所见即所得编辑面"不变；
  本计划是它的实现质量补齐，不新增产品能力边界。
- [render 模块](../modules/render.md)的不变量全部保留：过期预览不替换 current、图像/映射/几何
  同 revision 原子采纳、overlay 不写回 graph。乐观渲染属于"当前 revision 之上的过渡显示"，
  必须带状态标识，不冒充当前排版（同[硬性约束 6](../../AGENT.md)）。
- 编辑权威仍是语义文档图；页面编辑器是投影 + 工作缓冲，不引入第二个可写权威
  （同[硬性约束 2](../../AGENT.md)）。
- 框架仍为 egui（[ADR 0006](../adr/ADR-0006-native-ui-framework.md)）；本计划不触发新 ADR，
  除非 R5 立项后需要改变渲染架构结论。

## 阶段 R：渲染质量（模糊与口径）

- **R1 光栅比例跟随设备**：`pixel_per_pt = 显示 DPR × 显示 zoom`，按 (revision, page, 比例桶)
  缓存页纹理；缩放跨桶才重栅格化。
  通过判据：1x 与 2x 显示器、50%–200% 缩放档位下文字笔画边缘无可辨模糊（对照截图评审）；
  重栅格化不阻塞 UI 帧。
- **R2 字体打包与显式回退**：随应用分发 OFL 许可字体（CJK 衬线 + 拉丁衬线），登记于
  [字体资产许可](../adr/ADR-0011-font-asset-licenses.md)框架；系统字体仅作可选覆盖；
  字体缺失进诊断面板而非静默回退。
  通过判据：无系统字体的干净环境启动，正文/标题/公式字体正确且诊断无缺字体警告。
- **R3 耗时口径诚实化**：状态栏改报"击键→可见"端到端（至少编译+光栅），保留后端与
  revision 标识。
  通过判据：显示值与报告 0045 复测的端到端值误差 < 10%。
- **R4 乐观渲染**：编译未返回期间，在光标行用 egui 原生文本绘制本地缓冲内容，覆盖旧位图
  对应区域；排版结果到达后原子替换。状态标识"排版中"常显。
  通过判据：击键字符当帧可见（< 1 帧）；连续输入 60 字/分钟在 256 段文档上无"半秒后整串
  蹦出"体感；替换瞬间无闪烁错位（评审截图对比）。
- **R5 矢量渲染 spike**：Typst `Frame` → egui 图元（字形/形状）直绘，跳过位图光栅。
  这是 R1 的替代路线而非前置；立项后按[报告规则](../spikes/README.md)另立 spike 报告，
  失败则保留 R1 位图路线。

## 阶段 E：编辑体验（跟手与死区）

- **E1 坐标模型重建**：页面编辑器光标改用 `BlockPosition`（模型既有类型），拼接串只在提交
  diff 时临时构造；删除 `focus_after_split/merge/replace` 启发式，改按请求回声对账。
  通过判据：现有 `scholium-app` 全部测试通过且不再引用三字段；跨块选中/合并/拆分的光标
  位置由回声计算而非猜测（新增用例覆盖）。
- **E2 死区消除**：保留上一 revision 几何并按本次编辑量平移，编译期间点击/Home/End/上下键
  全部可用且语义正确。
  通过判据：人为将编译延迟注入 ≥500ms，期间点击任意位置光标落点与无延迟时一致；
  Home/End 为行首尾而非文档首尾。
- **E3 撤销**：基于动作日志实现本地 undo/redo，恢复 Ribbon 撤销/重做按钮。
  遵守[历史三层](../HISTORY_COLLABORATION.md)约束：这是产品动作层的最小实现，
  不冒充 CRDT 历史或 checkpoint。
  通过判据：文本/结构/类型变更可撤销与重做；连续撤销跨编辑类型不串状态。
- **E4 输入细节**：光标闪烁、双击选词、shift+点击扩选、IME 候选框跟随真实插入点、
  魔法数字具名化（AGENT.md 规模条款）。
- **E5 增量重排（可选，立项走 spike）**：段落粒度增量编译（利用 comemo 缓存按块拆分），
  目标把 256 段热态编译 p95 从 ~180ms 压到 < 30ms。立项前不承诺。

## 顺序与依赖

R6 = 每帧 O(文档) 开销消除（snapshot 改 `Arc` 共享、`buffer::text` 按 revision 缓存、
事件处理去整表克隆），它是 R4/E1 的前置——乐观渲染与回声对账都依赖低帧开销。
推荐执行序：**R6 → R4 → R3 → E2 → E1 → R1 → R2 → E3 → E4**；
R5/E5 独立立项。每步独立可交付、独立可回退，任一步失败不阻塞其余。

## 不做什么

- 不改权威模型、不加第二可写副本、不用 Git 做编辑同步（硬性约束 2/3/4）。
- 不引入 JS/TS、WebView 或 npm 依赖（硬性约束 10）。
- 不在本计划内扩产品能力（列表、表格、交叉引用等仍按路线图阶段归属）。
- 不搬运 `../mogan` 源码；其"单一权威树 + 投影 box tree + 光标 path 锚定"的结论
  经评审吸收进 E1 的设计方向（见[开发日志](../log/render-edit-review.md)）。
