# P1 排版工作区规划

本页规划[阶段 1](ROADMAP.md#阶段-1两个内核的打开编辑预览保存输出闭环)的应用壳与编辑入口。
产品定位为科学排版软件，服务论文、书籍、技术文档和研究写作；P1 的基础文本、数学与文件闭环是实现子集，
不能据此把产品收窄成笔记软件。本页作为后续实施与评审的布局基准，不要求逐像素复刻，也不表示对应功能已经实现或通过验收。
正式界面沿用 Rust / egui 原生路线；设计稿仅表达布局、令牌与操作关系，不作为应用 UI 技术验证依赖。

## 如何参照执行

开工前先读[体验规范的工作区原则](../EXPERIENCE.md#工作区组织)，再按本页安排布局与操作入口。
原则约束交互关系，参考图与令牌表帮助理解空间关系和视觉层级，具体控件服从原生平台、可访问性和真实编辑需要。

| 层级 | 执行方式 |
|---|---|
| 必须保持的原则 | 科学排版定位；页面编辑是单一编辑面；源码与预览同等重要；文件操作归属文件菜单；正文优先；权威模型及构建状态不含混 |
| 默认起点 | 自上而下为菜单栏、主工具栏、焦点工具栏、文档标签栏、编辑区、状态栏；源码与预览约 1:1；文件导航和诊断默认收起；菜单、工具栏、焦点工具栏与快捷键调用同一命令 |
| 可自行优化的细节 | 字体回退、图标、几像素间距、菜单分组顺序、缩放策略、窄窗口折叠方式；可因平台和文档类型调整 |
| 不应照搬的示例 | 示例文稿、作者、菜单中尚未交付的能力、设计稿中的纸面排版细节（纸面由 Typst 实际排版）、截图的滚动与裁切 |

日常细节调整不另设确认门槛：实现者应根据可读性、空间利用、键盘/IME 与无障碍表现作判断。
改变主要区域关系或工作方式时，同一变更先更新对应规范与本页，并在评审说明中给出原因及前后界面对照；
不必为颜色或几像素差异修改整套规划。阶段范围仍由路线图约束，不能因为图上有某个入口就提前扩展 P1。

## 布局变更：由 Ribbon 改为三栏工具区

早期规划采用 Office 式 Ribbon。实际实现后，Ribbon 约占 170 逻辑像素，分组空旷、层级混乱，
与科学排版软件的使用方式不符；[路线图](ROADMAP.md)阶段 1 本就写明“标准菜单与紧凑工具栏”。
新布局参考 Mogan 的菜单栏、图标栏与随焦点变化的上下文栏三层结构（只借鉴结构，不复用其实现，
见[开发规范](../../AGENT.md)第 1 条），以及 [ArtCraft / PhotoCraft / WordCraft 借鉴计划](ARTCRAFT_REFERENCE.md)中的设计令牌做法。
顶部四栏合计 122 逻辑像素，比 Ribbon 节省约 50 像素且每栏职责单一。
本页的设计稿（2026-10-14 由 Claude Design 按本项目需求生成）替代此前的工作区草图。

## 2026-11-03 修订：界面精修

[全界面截图审查](../log/2026-11-03-ui-audit.md)发现：外壳没有按项目语言装配，大量入口灰显，开发信息外露，
对话框简陋，诊断收不到 LaTeX 错误。用户确认的方向是：以 2026-10-14 设计稿为底精修，做适度的现代化，增加起始页；
观感参考 Zed / JetBrains 新 UI 与 Typora / Obsidian：克制、扁平、信息密度高、正文为主。
不使用卡片式面板、胶囊标签、装饰性阴影、渐变或大面积强调色。新设计稿在 `assets/p1-ui/2026-11/`，
与 10-14 的图同属布局参考，不是像素验收样本。

本修订替换以下旧条款，正文对应位置已同步改写：

| 旧条款 | 改为 |
|---|---|
| 未实现项在菜单、工具栏、溢出菜单中灰显并保留位置 | 未实现的命令不出现；只有“当前不可用但已实现”的命令灰显（例如没有可重做的动作） |
| 已确认决策 3：焦点工具栏显示禁用的文档属性下拉框 | 文档属性可编辑前不出现在焦点栏；Typst 正文焦点栏只放实际可用的操作 |
| 令牌中 border `#8C8C8C`、三层工具栏三种底色 | 边框调浅，菜单栏、主工具栏、焦点栏同一底色，层次靠间距与 1px 分隔线 |
| 分隔线一律不用阴影 | 各栏仍不用阴影；弹出层与对话框用一层很浅的阴影把它们和下层分开 |

### 外壳按项目语言装配

工作区按项目语言决定工具栏、焦点栏、菜单和状态栏的内容。命令注册表为每条命令声明适用的内核，
不适用的命令在该项目里不出现，而不是灰显。

| 区域 | Typst 原生项目 | `.typ` 源码项目 | LaTeX 项目 |
|---|---|---|---|
| 主工具栏 | 段落样式、粗体斜体、公式结构、撤销重做 | 撤销重做 | 段落样式（插入 `\section` 等）、章节、环境、公式、引用、图片、表格、撤销重做、整编 |
| 焦点栏（左） | 正文：可用的正文操作；公式：数学结构与快捷键 | 光标位置面包屑 | 光标位置面包屑，如 `main.tex › 1 引言 › equation`，点击任一级跳转；进入公式时显示数学结构操作 |
| 焦点栏（右） | 页面编辑 / 源码预览 | 同左 | 同左。L3 之前点“页面编辑”显示整页预览，并说明页面公式编辑在阶段 3 提供 |
| 状态栏 | 页码、字数、上下文、问题计数、Typst 同步状态、缩放 | 行列、问题计数、Typst 同步状态、缩放 | 行列、字数、问题计数、引擎与预览状态（如“LuaLaTeX · 实时 52 ms”）、缩放 |

主文件、引擎、参考文献工具等很少改动的项目参数放在“文档 → 项目设置…”，不占焦点栏；
状态栏的引擎状态点击后打开项目设置。

### 起始页

没有打开项目时显示起始页，见 `2026-11/start-page.png`：应用名与一句定位；“开始”（新建项目、打开、从旧版本导入，各带快捷键）、
“最近”（项目名、路径、语言）、“环境”（TeX Live 与随应用安装的 rtex 是否就绪，缺失时给出安装说明与“重新检测”）三组纯文字列表。
悬停才出现底色，不用卡片或插图。项目被另一进程打开时，在起始页顶部说明是哪个项目，并提供“重试”。

### 源码编辑器与预览窗格

两种语言共用的源码编辑器占满窗格高度，带行号、当前行高亮和行号旁的问题标记；高亮与诊断由内核提供。
源码与预览之间的分隔条可拖动、可用键盘调整，双击恢复等宽。预览窗格中纸面居中，状态栏缩放与“适合宽度”作用于预览，
缺工具链或构建失败时显示居中说明和可执行的操作，保留上次成功的结果并标明它对应的版本。
`.typ` 源码项目同样是源码加 Typst 预览两栏，打开后焦点在源码编辑器。
生成的 Typst 源码保持只读，补上行号、高亮与当前块高亮，标题只写“由文档生成 · 只读”。

### 问题面板

问题面板取代现有诊断面板，做法与 IDE 一致，见 `2026-11/latex-workbench.png`：

- 一行一个问题：严重级别图标（错误为圆点、警告为三角、信息为圆圈）、消息、`行:列`；按文件分组，组标题显示文件名与条数。
- 单击或回车跳到源码对应位置并选中出错范围；Typst 原生项目跳到页面上的对应节点。F8 / Shift+F8 前后切换（经键位表绑定）。
- 面板顶部有“问题”与“构建输出”两页，右侧显示错误与警告计数。状态栏常驻同样的计数，点击打开面板。
- 后端、revision、缓存命中、布局耗时等开发信息不进入问题面板；只在 `SCHOLIUM_EDITOR_AUDIT` 输出中保留。

### 对话框

所有对话框共用一套规格：标题栏左侧为标题、右侧为关闭按钮；内容区 18 px 内边距；底部按钮靠右，主按钮为强调色实心，
其余为描边按钮。Enter 触发主按钮，Esc 等于取消。字段错误在字段下方就地显示。对话框宽度不超过窗口宽度减 32 px，窄窗口内可滚动。

- **新建项目**（`2026-11/new-project.png`）：语言单选（LaTeX 默认，附一句说明）、模板、名称、位置（带“浏览…”），下方提示将创建的路径；
  引擎有默认值，以后在项目设置中更改。
- **打开**：直接调用系统文件选择器，可以选文件夹或 `.tex`/`.typ` 文件；多入口目录在随后的小对话框中选择主文件。
  “从旧版本导入”放在起始页和文件菜单，不放在打开对话框里。
- **项目设置**（`2026-11/project-settings.png`）：主文件、引擎（说明实时与整编的区别）、参考文献工具；项目语言只读显示。
- **外部修改冲突**（`2026-11/external-conflict.png`）：标题写明哪个文件、什么时候被改；正文一句说明为什么没保存，一句说明各操作的后果；
  操作为“查看差异”（左侧）以及“取消 / 重新载入 / 另存为…”，主按钮是两边都不丢内容的“另存为…”。

### 命令框与悬停提示

`\` 命令框贴在光标下方，候选行显示符号、命令名和类别，底部一行键盘提示，见 `2026-11/typst-math-focus.png`。
悬停提示只在能补充信息时出现，例如快捷键、不可用的原因；不重复按钮上已有的文字。

### 先定接口、按顺序实现的部分

- **文件选择器**：`FilePicker` 接口有两种实现，系统选择器（Linux 走 xdg-desktop-portal）和应用内路径输入回退；
  系统选择器的依赖评估与接入排在对话框批次之后，接口先行。
- **诊断**：统一的诊断条目包含严重级别、来源内核、资源路径、行列范围、消息与可选代码。问题面板只消费这个结构；
  rtex 诊断与 Typst 编译诊断先接入，TeX 日志解析（`latex.md` 的 `log.rs`）作为后续来源接入同一结构。
- **工具链状态**：rtex 版本（随应用打包）、TeX Live 与可用引擎，由起始页、项目设置和预览空状态共用。

### 实施顺序

每批交付都附中英文、浅深色的前后对照截图，并跑完 window checks。

1. 令牌与基础组件（按钮、输入框、下拉框、分段切换、弹出层、对话框框架、Esc/Enter 规则），命令按内核声明适用范围，
   移除未实现入口与开发信息。
2. 起始页与对话框（新建、打开、项目设置、外部修改冲突、项目被锁、旧会话迁移），`FilePicker` 接口与应用内回退。
3. 共享源码编辑器与预览窗格：LaTeX 工作区按本节重排、`.typ` 源码项目加预览、rtex 随应用打包、工具链状态。
4. 问题面板与诊断结构，接通 LaTeX 诊断（审查发现 1），跳转与 F8。
5. 焦点栏面包屑、命令框与状态栏，窄窗口与深色主题复核。

## 两种工作方式

### 页面编辑

页面中的排版内容就是编辑对象：光标、选区、中文输入、结构数学和焦点都在这里工作。
即时排版直接更新该编辑面，**不在右侧重复显示预览**，也不为独立预览预留空栏。
默认收起文件导航和诊断；页面视口使用标签栏以下、状态栏以上的全部空间。
连续编辑、分页显示与最终排版检查是视图职责，不把排版软件等同于一个带预览的小型笔记页。

正文纸张边距由排版样式决定，工作区外边距保持紧凑。编辑区按缩放与窗口宽度显示内容，
不能靠缩小正文和放大空白来制造“简洁”。纸面在深浅两套主题中都是白色排版结果。
LaTeX 发布目标的最终检查由“文档”菜单按需打开，不占据日常页面编辑布局。

### 源码与预览

主工作区分为左右两个同等重要的窗格：左侧源码，右侧排版结果，默认 **50% / 50%**。
比例按扣除文件导航后的剩余宽度计算；分隔条可拖动、用键盘调整并恢复等宽。
源码窗格显示语言、文件或生成视图来源（生成视图标“只读 · 由文档生成”）；预览窗格显示实际后端、同步/过期和构建状态。
预览支持缩放、适合宽度与点击定位，不使用固定 220–300 像素的小型缩略图代替工作预览。

同一文档切换工作方式不改变权威模型：

- 原生项目的源码为生成视图；显式开始编辑后成为独立草稿，检查并应用后才修改正文。
- 外部 `.tex` / `.typ` 项目直接编辑权威源文件；语法错误仍能保存，使用对应原生后端构建。
- 切换可查看的生成方言不等于切换可写语言；有草稿时须先提交、保存或显式处置，再进入另一语言写入。
- 草稿未应用或构建失败时，保留上次成功排版并明确它对应的内容版本，不伪装当前草稿已经生效。

## 区域与空间分配

窗口标题栏与最小化、最大化、关闭按钮由操作系统提供，应用不自绘；文档名与修改标记显示在系统标题中。

| 区域 | 高度（逻辑像素） | 布局与职责 |
|---|---|---|
| 菜单栏 | 28 | 文件 编辑 插入 格式 文档 视图 工具 帮助；纯文字、左对齐，样式朴素如原生菜单。菜单树由命令注册表生成 |
| 主工具栏 | 36 | 纯单色线性图标，按组用竖分隔线隔开；每个图标有悬停提示“名称 + 快捷键”；当前格式生效时为激活态；只放当前内核已实现的命令（2026-11-03 修订）；最右侧为命令搜索 |
| 焦点工具栏 | 32（含底部 1px 分隔） | 内容随项目语言与光标所在节点变化，见“2026-11-03 修订”的装配表：Typst 正文为可用的正文操作，公式中为“公式”标记与结构操作；源码项目为光标位置面包屑。最右侧固定为“页面编辑 / 源码预览”分段切换 |
| 文档标签栏 | 30（标签本体 26） | 位于三栏工具区下方、编辑区上方；每个文档一个标签（文件名、未保存圆点、关闭），当前标签与编辑区同色相连，末尾“+”；只有一个文档时也显示 |
| 主编辑工作区 | 余下全部 | 页面编辑为居中 A4 页面与浅灰画布；源码模式为等宽双窗格，二者互斥 |
| 可选辅助面板 | — | 文件导航与问题面板由“视图”菜单展开；问题面板也可由状态栏的问题计数展开；均默认不挤占正文 |
| 状态栏 | 24（含顶部 1px 分隔） | 按项目语言装配（见修订节）：左为位置、字数与上下文；右为问题计数（点击打开问题面板）、内核与预览状态（如“Typst · 已同步”“LuaLaTeX · 实时 52 ms”，点击打开项目设置）、缩放与适合宽度。revision 等开发信息只进入 AUDIT 输出 |

窄窗口（如 1024×700）时，主工具栏放不下的按钮按组收进“»”溢出菜单，焦点工具栏下拉框收窄并截断，
菜单栏、模式切换与命令搜索始终可见。辅助导航展开时建议约 166–220 逻辑像素并允许调整，源码与预览继续平分余下宽度。
正式桌面应依据可读字号选择保留分屏或切换单窗格，不能默认把预览缩成缩略图。
这些尺寸需要在原生字体、DPI、输入法与辅助功能环境下检验；不可牺牲文字或点击目标可用性。

## 菜单、工具栏与焦点工具栏组织

菜单、主工具栏、焦点工具栏、溢出菜单、命令搜索与快捷键都来自同一命令注册表（[借鉴计划](ARTCRAFT_REFERENCE.md)采纳项 1），
启用、选中状态与不可用原因由命令判定统一给出；不同入口不得各自维护一份命令或快捷键。

- **文件**：新建、打开、最近打开、保存、另存为、导出、关闭。打印入口属于整体产品规划，单独确定交付阶段。
- **编辑**：撤销、重做、剪切、复制、粘贴、查找与替换。
- **插入**：行内/独立公式、分数、根式、上下标与定界符；以后扩展表格、图片、链接、引用等文档对象。
- **格式**：粗体、斜体、下划线、删除线、清除格式；段落样式子菜单（正文、标题 1、标题 2）。
- **文档**：样式与模板、页面与纸张、文档语言、正文字体与字号、最终排版检查；能力按阶段开放。
- **视图**：工作方式、文件导航、诊断、缩放与分屏、主题；改变显示不应修改文档内容。
- **工具**：命令搜索、偏好设置；以后扩展格式转换等工具。
- **帮助**：快捷键、命令说明与应用信息。

主工具栏分组：段落样式与结构（列表、代码块）｜文字格式（粗体、斜体、下划线、删除线、清除格式）｜
插入（行内公式、分数、表格、图片、链接）｜历史（撤销、重做）｜命令搜索（最右）。

未实现的能力不出现在菜单、工具栏与溢出菜单中；已实现但此刻不可用的命令置灰，原因放在悬停提示里，不写进标签文字（2026-11-03 修订）；
只读生成源码、组合输入等状态不能因切换入口而绕过写入门禁。
剪贴板和格式命令须保留页面语义光标/选区，完成后继续在页面输入，不引入第二个正文编辑区。

导出从文件菜单进入模态流程，不常驻按钮卡片；兼容报告列出降级、阻断、源位置和依赖。
输出锁定 revision，未解决问题阻止正式输出；保存写当前项目，另存为创建独立项目，导出生成副本。
恢复在重新打开异常会话时触发，显示可恢复正文动作与独立草稿，不做成一个日常工作标签。
外部文件冲突按事件触发比较与解决界面，不静默覆盖磁盘内容或本地修改。

## P1 实施边界

设计稿使用同一篇技术文稿呈现各状态；文稿只采用段落、标题、强调与基础公式作为内容示例。
显示的纸张、作者与文档属性用于检验排版工作区的空间关系，并不表示完整模板系统或可编辑文档属性已经交付。
源码与页面是设计示意，不能作为两种编译器渲染一致、源码可编辑或 round-trip 通过的证据。

P1 仍以原生编辑、Action/undo、保存重开、强杀恢复、最小 Source Studio、受支持子集源码/PDF 交换为出口。
LaTeX 项目在同一工作区以“源码与预览”方式打开（LaTeX 工作区 L1），与 Typst 项目同阶段交付。
完整焦点工具栏、结构大纲、复杂文档对象按阶段 2 扩展；完整 source lens 与 LaTeX 页面内编辑按阶段 3 扩展。
协作、非线性历史等面板依各阶段接入，避免将尚未可用的功能堆到主界面。

所有正文写入产生 Action；草稿单独持久化。编译不阻塞输入、导航或保存；过期映射必须校验后才能定位。
真实焦点、TreeCursor、IME、读屏和键盘操作在原生实现中验收；设计稿不能替代这些门禁。
实施前置继续遵守[阶段 1 接手门禁](../spikes/SPK-0012-exit-criteria.md#阶段-1-接手门禁不继续扩充-p0)。

## 实施与评审检查

每次涉及应用壳或主要布局的变更，按相关项检查；这是布局评审依据，不代替阶段出口与原生编辑验收。

- Typst 原生项目默认进入页面编辑后，页面可直接编辑，没有常驻的重复预览或为其留下的空栏。
- 顶部只有菜单栏、主工具栏、焦点工具栏与标签栏四栏，高度符合令牌；应用不自绘窗口标题与窗口按钮。
- 光标在正文与公式之间移动时，焦点工具栏随之切换，状态栏上下文同步变化；切换不修改文档 revision。
- 菜单、工具栏、溢出菜单、命令搜索与快捷键来自同一命令注册表；未实现的命令不出现，已实现但此刻不可用的命令置灰并在提示中说明原因；
  LaTeX 与 `.typ` 源码项目里不出现 Typst 原生文档专用的入口。
- 切换源码时，左右窗格初始接近等宽；调整窗口、分隔条或导航栏后，两边仍能完成实际编辑/查看任务。
- 新建、打开、保存、另存为、导出在文件菜单中可找到；常用操作可由工具栏和键盘访问。
- 点击粘贴、公式、段落样式后，输入继续落在原页面光标。
- 切换工作方式不改变权威模型；生成源码、草稿与外部源文件的可写性和保存含义清楚。
- 草稿错误或构建失败仍能保存；预览标明旧结果对应的版本与过期状态，revision 等开发信息只在 AUDIT 输出中出现。
- 问题面板一行一个问题，单击或回车跳到对应位置；LaTeX 与 Typst 的错误都能进入问题面板。
- 对话框 Esc 取消、Enter 触发主按钮；窄窗口下不超出窗口。
- 1×、1.5×、2× 缩放与 1440×900、1024×700 窗口下，深浅两套主题均无文字溢出、换行挤压或遮挡；
  控件、公式和输入法候选不被遮挡；键盘与读屏可访问核心操作。
- 交付时提供原生界面与设计稿的对照图，说明主要偏离及理由；不以设计稿证明真实编辑能力。
